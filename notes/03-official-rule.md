# 公式の ω-Y の展開規則

3 つ目のノートである。公式の ω-Y の展開を、山の座標（列、行、父）の言葉で完全に書き起こす。調べた日は 2026-09-23 である。

- 公式の定義は、Naruyoko 氏の [StudyAndExpandSequence](https://github.com/Naruyoko/StudyAndExpandSequence) の `expand` である（コミット `b26ba7e`、v1.1 の既定の設定）。ライセンスが無い。
- 規則は、このプログラムの動きを調べ、実行して出力を比べて書き起こした。コードは写していない。
- 自前の実装 [reference/official/omegay.cjs](../reference/official/omegay.cjs) は、このノートの規則から書いた。試験したすべての展開で、公式のプログラムと一致した（§6）。

## 0. 要約

- 公式の展開は、**帯ごとに 1-Y の規則を当てはめる入れ子の写し**である。帯とは、行の高い次数の係数が等しい行の集まりである（§1.3）。
- 帯ごとに、写す列が「上がる」かを、その帯の参照の行（根の行のひとつ下の行）の中の祖先で決める。上がる列は、根の高さより上の段を持ち上げる。すき間の段には、根の行を写す（§2.4）。
- 自前の実装は、試験したすべての展開で公式と一致した。標準形の式 13030 個の展開 39090 回と、合法な列 16778 個の展開 50334 回である（重複を除く。§6）。
- 01-feasibility §2.5 で残った 9 回の食い違いの原因は、**上がるかどうかを参照の行で決めること**だった。01 の推測（世代の数ですき間の高さが決まる）は、この 9 回の原因ではなかった。世代の数は、入れ子のすき間の高さ（§2.4 の場合 4）で使われる。
- Phyrion 氏の weak の規則（[Build.lean](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean/blob/main/OmegaY/Expansion/Build.lean)）との違いは 3 つある（§4）。
  1. 持ち上げる節点の選び方：weak は marker（`markers`、`weakReaches`）、公式は帯ごとの参照の行の祖先。
  2. 持ち上げる量：weak は境界の列の参照（`referenceAt`）、公式は帯の中の高さの差。
  3. すき間の充填：weak は制御の辺の父の列（`fill`）、公式は根の行の写し。

## 1. 記法

### 1.1 行

- 行は $`ω^ω`$ 未満の順序数 $`ρ = \sum_k ρ_k ω^k`$ である。$`ρ_k`$ を $`ρ`$ の $`k`$ 次の係数と呼ぶ。最下行は 0 である。
- 跳び：$`\mathrm{jump}(α, β) = 0`$（$`α = β`$ のとき）。そうでなければ、$`α, β`$ の係数が違う最も高い次数に 1 を足したもの。
- $`ρ + ω^e`$ は順序数の和である。$`e`$ 次より下の係数は消える。

### 1.2 山

- $`s = (s_0, …, s_{x_0})`$ の山 $`M(s)`$ は、00-survey §1.3 の正準の山である。Naruyoko 氏の `calcMountain` の山と一致する（01-feasibility の I7）。
- 節点は（列 $`c`$、行 $`ρ`$）で決まる。値を $`v(u)`$ と書く。
- 最下行でない節点 $`u`$ には父 $`π(u)`$ がある。$`u`$ のすぐ下の節点から $`u`$ への辺の、左の端点である。$`π(u)`$ の列は $`u`$ の列より左にある。
- $`u^+`$ は、同じ列で $`u`$ のすぐ上の節点である。
- 値の規則：列の一番上の節点の値は 1 である。$`v(u) = v(u^+) + v(π(u^+))`$ である。

**行の中の父.** 節点 $`u`$（行 $`ρ`$）について、$`u^+`$ があり、$`π(u^+)`$ の行が $`ρ`$ に等しいとき、$`P(u) = π(u^+)`$ とする。このとき $`u^+`$ の行は $`ρ + 1`$ である。そうでなければ $`P(u)`$ は無い。

$`P`$ は同じ行の中の木を作る。1-Y の山の「親」に当たる。Naruyoko 氏のプログラムは、行ごとに持つ親の番号でこの木を表す。正準の山では、上の辺の父から読み取れる。

### 1.3 帯と段

$`d ≥ 1`$ と行 $`β`$ について、水準 $`d`$ の帯を次で定める。

```math
B_d(β) = \{\, ρ \;:\; ρ_k = β_k \ (k ≥ d-1) \,\}
```

- 水準 1 の帯は、ひとつの行 $`\{β\}`$ である。
- 水準 2 の帯は、有限の部分だけが違う行の集まりである（1-Y の山ひとつ分。Miraheze の記事の「富士山」）。
- 水準 $`d ≥ 2`$ の帯 $`S`$ は、段 $`S[j]`$（$`j ∈ ℕ`$）に分かれる。$`S[j]`$ は $`S`$ の中で $`ρ_{d-2} = j`$ となる行の帯で、水準は $`d-1`$ である。
- $`S`$ の中の行 $`ρ`$ の高さを $`h_S(ρ) = ρ_{d-2}`$ とする。段は高さの順に並ぶ。段の中の行は、上の段の行より小さい。
- $`\mathrm{top}_S(c)`$：列 $`c`$ の節点で、行が $`S`$ に入る最も高いもの。無いこともある。

## 2. 規則

### 2.1 根と区画

- $`t`$：列 $`x_0`$ の一番上の節点。$`τ = \mathrm{row}(t)`$。
- $`s_{x_0} = 1`$ なら $`t`$ は最下行にあり、父が無い。このとき $`s[n]`$ は $`s`$ の末項を消したものである。以下 $`s_{x_0} \gt 1`$ とする。
- 根 $`r = π(t)`$、根の列 $`c_r`$、幅 $`w = x_0 - c_r`$。
- $`n = 0`$ なら $`s[0]`$ は末項を消したものである。以下 $`n ≥ 1`$ とする。
- 列の写像：$`φ_i(c) = c`$（$`c \lt c_r`$）、$`φ_i(c) = c + iw`$（$`c ≥ c_r`$）。
- 出力の列は、$`M(s)`$ の列 $`0, …, x_0-1`$ と、次の列 $`X = x + iw`$ である。$`i = 0, 1, …, n`$ の順に、$`x`$ は小さい順に作る。

```math
x ∈ \begin{cases} \{x_0\} & (i = 0) \cr \{c_r+1, …, x_0\} & (1 ≤ i \lt n) \cr \{c_r+1, …, x_0-1\} & (i = n) \end{cases}
```

- 源はいつも元の山 $`M(s)`$ である。減一の山 $`M(s')`$ は使わない。ただし、$`i = 0`$ で作る列 $`x_0`$ は、試験のすべてで $`M(s')`$ の列 $`x_0`$ に一致した（§6 の検査 (a) から出る）。
- $`s[n]`$ は、出来た列の最下行の値を並べたものである。

### 2.2 列の組み立て

列 $`X = x + iw`$ は、組 $`(ρ', ℓ)`$ の列から作る。組は下の部分（§2.3、§2.4）、上の部分（§2.5）の順に出る。行 $`ρ'`$ は狭義に増える。

- 組 $`(ρ', ℓ)`$ は、行 $`ρ'`$ に節点 $`u`$ を置く。
- $`ℓ`$ が無ければ $`u`$ に父は無い（最下行の節点）。
- $`ℓ`$ があれば、$`u`$ の父は、出力の列 $`φ_i(ℓ)`$ の節点で、行が $`ρ'`$ より小さい最も高いものである。$`φ_i(ℓ) \lt X`$ なので、その列は出来ている。
- 値は上から決める。一番上の節点は 1、ほかは $`v(u) = v(u^+) + v(π(u^+))`$。

### 2.3 下の部分：項目の処理

$`τ`$ より下の行は、$`τ`$ で決まる帯に分ける。各 $`k ≥ 0`$ と $`j \lt τ_k`$ について、

```math
L_{k,j} = \{\, ρ \;:\; ρ_m = τ_m\ (m \gt k),\ ρ_k = j \,\}
```

は水準 $`k+1`$ の帯である。これらは $`[0, τ)`$ を分け、$`k`$ の大きい順、$`j`$ の小さい順に並べると行の順になる。

項目は 5 つ組 $`(S, T, C, o, b)`$ である。

- $`S`$：源の帯（$`M(s)`$ の中）。$`T`$：行き先の帯。$`S`$ と $`T`$ の水準は同じである。
- $`C`$：根の行を写すときの源の行。写さないときは $`⊥`$。
- $`o ∈ ℕ`$：ずれ。$`b ∈ \{0, 1\}`$：帯の下の方を写さないかどうか。

最初の項目の列は $`(L_{k,j}, L_{k,j}, ⊥, 0, 0)`$ を行の順に並べたものである。項目を先頭から順に処理する。水準 1 の項目は組をひとつ出すか、何も出さない。水準 2 以上の項目は、その場で子の項目の列（$`j`$ の小さい順）に置き換わる（深さ優先）。

**水準 1 の項目.** $`S = \{σ\}`$、$`T = \{θ\}`$ とする。

- 列 $`x`$ に行 $`σ`$ の節点が無ければ、何も出さない。
- $`C = ⊥`$：組 $`(θ, ℓ)`$ を出す。$`ℓ`$ は節点 $`(x, σ)`$ の父の列である。$`σ = 0`$ なら $`ℓ`$ は無い。
- $`C ≠ ⊥`$：組 $`(θ, ℓ)`$ を出す。$`ℓ`$ は節点 $`(x, C)`$ の父の列である。$`C = 0`$（最下行）なら $`ℓ = x - 1`$ とする。

### 2.4 水準 2 以上の項目

$`S`$ の水準を $`d ≥ 2`$ とする。$`M(s)`$ で次を取る。

- $`a = \mathrm{top}_S(x)`$。無ければ何も出さない。
- $`κ = \mathrm{top}_S(x_0)`$、$`ρ = \mathrm{top}_S(c_r)`$。
- 高さ $`h_a, h_κ, h_ρ`$（$`h_S`$ で測る。節点が無ければ 0）。

**上がるかどうか.** 次の条件を $`A(S, x)`$ とする。

- $`ρ`$ がある。
- 参照の行 $`Z`$ を、$`\mathrm{row}(ρ)_0 \gt 0`$ なら $`\mathrm{row}(ρ) - 1`$（有限の係数を 1 減らした行）、そうでなければ $`\mathrm{row}(ρ)`$ とする。
- 節点 $`(x, Z)`$ があり、行の中の父をたどる列 $`(x, Z), P(x, Z), P^2(x, Z), …`$ の中で、列が $`c_r`$ 以下になる最初の節点の列が、ちょうど $`c_r`$ である。

1-Y（BMS）の上がる列の判定を、帯ごとに行うものである。

記号：$`Δ = (h_κ - h_ρ) \cdot i`$、$`e = 1`$（$`d = 2`$ のとき）、$`e = 0`$（$`d ≥ 3`$ のとき）。

$`q = \mathrm{top}_T(c_r + iw)`$ を、**出力**の列 $`c_r + iw`$（ひとつ前の区画の境界の列。$`i = 1`$ では $`i = 0`$ で作った列 $`x_0`$）から取る。$`h_q = h_T(\mathrm{row}(q))`$（無ければ 0）とする。

子の項目を、場合に分けて次のように作る。

**場合 1：$`A(S,x)`$ でないとき.** そのまま写す。$`j = 0, …, h_a`$ について $`(S[j], T[j], ⊥, 0, 0)`$。

**場合 2：$`A(S,x)`$、$`C = ⊥`$、$`b = 0`$ のとき.** 持ち上げる。$`j = 0, …, h_a + Δ`$ について、

| 範囲 | 子の項目 |
|---|---|
| $`j \lt h_ρ`$ | $`(S[j], T[j], ⊥, 0, 0)`$ |
| $`h_ρ ≤ j \lt h_ρ + Δ + e`$ | $`(S[h_ρ], T[j], \mathrm{row}(ρ), 0, [j \gt h_ρ])`$ |
| $`j ≥ h_ρ + Δ + e`$ | $`(S[j - Δ], T[j], ⊥, 0, [i ≠ 0 ∧ j = h_ρ + Δ])`$ |

$`[\,\cdot\,]`$ は、成り立てば 1、成り立たなければ 0 である。根の高さより下の段はそのまま、上の段は $`Δ`$ だけ持ち上げる。すき間の段には根の行 $`\mathrm{row}(ρ)`$ を写す。

**場合 3：$`A(S,x)`$、$`C = ⊥`$、$`b = 1`$ のとき.** 帯の下の方（$`h_ρ`$ より下）を写さない。$`H = h_q + h_a`$（$`i = 0`$ なら $`H = h_a`$）とし、$`j = h_ρ, …, H`$ について、

| 範囲 | 子の項目 |
|---|---|
| $`j \lt h_ρ + h_q + e`$ | $`(S[h_ρ], T[j - h_ρ], \mathrm{row}(ρ), 0, 1)`$ |
| それ以外 | $`(S[j - h_q], T[j - h_ρ], ⊥, 0, [j = h_ρ + h_q])`$ |

**場合 4：$`A(S,x)`$、$`C ≠ ⊥`$ のとき.** 根の行を写している途中である。世代の数 $`g`$ を次で決める。

- $`C ≠ 0`$ なら、次の回数。列 $`c`$ から「節点 $`(c, C)`$ の父の列」へ移る操作を、$`x`$ から始めて、列が $`c_r`$ 以下になるまで繰り返す回数。
- $`C = 0`$ なら、$`g = x - c_r`$（最下行では、左の脚はひとつ左の列である）。

$`H = h_q + g - o`$（$`i = 0`$ なら $`H = h_a`$）とし、$`j = 0, …, H`$ について、$`o_j = \max(j - h_q + o,\ 0)`$ として、

| 条件 | 子の項目 |
|---|---|
| $`b = 1`$ | $`(S[h_ρ], T[j], C, o_j, 1)`$ |
| $`b = 0`$、$`j \lt h_ρ`$ | $`(S[j], T[j], ⊥, 0, 0)`$ |
| $`b = 0`$、$`j ≥ h_ρ`$ | $`(S[h_ρ], T[j], C, o_j, [j \gt h_ρ])`$ |

**起こらない場合.** $`A(S,x)`$ でないのに $`C ≠ ⊥`$、$`o ≠ 0`$ または $`b = 1`$ の場合、場合 4 で $`b = 0`$ なのに $`q`$ が無いか $`o ≠ 0`$ の場合、場合 4 と水準 1 で節点 $`(x, C)`$ が無い場合、世代をたどる途中で行 $`C`$ の節点が無い場合、行が狭義に増えない場合。公式のプログラムはこれらで止まるか、意味の無い値を出す。自前の実装は例外を投げる。試験したすべての展開で、どれも起こらなかった。

### 2.5 上の部分

$`x' = x`$（$`x \lt x_0`$）、$`x' = c_r`$（$`x = x_0`$）とする。列 $`x'`$ の節点 $`u`$ で行が $`τ`$ 以上のものについて、下から順に組 $`(\mathrm{row}(u), ℓ)`$ を出す。$`ℓ`$ は $`π(u)`$ の列である。$`τ`$ 以上の行は持ち上げない。

### 2.6 例

**$`(1,3,3)[2]`$.** $`M(s)`$ の列 1 と列 2 は `0, 1←c0@0, ω←c0@0` である。$`t = (2, ω)`$、$`r = (0, 0)`$、$`c_r = 0`$、$`w = 2`$、$`τ = ω`$。下の帯は $`L_{1,0} = [0, ω)`$（水準 2）だけである。

列 4（$`i = 1`$、$`x = 2`$）：

- $`S = L_{1,0}`$ で、$`a = (2,1)`$、$`κ = (2,1)`$、$`ρ = (0,0)`$。$`h_a = h_κ = 1`$、$`h_ρ = 0`$、$`Δ = 1`$、$`e = 1`$。
- 参照の行は 0（$`\mathrm{row}(ρ)_0 = 0`$）。最下行の $`P`$ は、左にある値の小さい最も近い項である。$`(2,0) → (0,0)`$ で、$`A`$ が成り立つ。
- 場合 2：$`j = 0, 1`$ は根の行（最下行）の写し、$`j = 2`$ は段 1 の持ち上げ。
- $`j = 0`$：$`C = 0`$ なので $`ℓ = x - 1 = 1`$。行 0 なので父は無い。
- $`j = 1`$：$`ℓ = 1`$、$`φ_1(1) = 3`$。父は列 3 の行 0。
- $`j = 2`$：源は $`(2, 1)`$、父の列 0、$`φ_1(0) = 2`$。父は列 2 の行 1。
- 上の部分：列 2 の行 $`ω`$ の節点は $`τ`$ 以上だが、$`x = 2 = x_0`$ なので $`x' = c_r = 0`$ を見る。列 0 には $`ω`$ 以上の節点が無い。
- 結果は `0, 1←c3@0, 2←c2@1`。値は 7。$`s[2] = (1,3,2,5,7,12)`$ である。

**$`(1,4,4)[2]`$ の列 4（場合 4 の例）.** $`M(s)`$ の列 1 と列 2 は `0, 1←c0@0, ω←c0@0, ω²←c0@0` である。$`τ = ω^2`$ で、下の帯は $`L_{2,0} = [0, ω^2)`$（水準 3）である。

- 水準 3：$`h`$ は $`ω`$ の係数である。$`h_a = h_κ = 1`$、$`h_ρ = 0`$、$`Δ = 1`$、$`e = 0`$。場合 2 で、$`j = 0`$ は根の行（行 0）の写し $`(S[0], T[0], 0, 0, 0)`$、$`j = 1`$ は持ち上げ $`(S[0], T[1], ⊥, 0, 1)`$、$`j = 2`$ は持ち上げ $`(S[1], T[2], ⊥, 0, 0)`$ である。
- $`j = 0`$ の子（水準 2、場合 4、$`b = 0`$）：$`C = 0`$ なので $`g = x - c_r = 2`$。$`q`$ は出力の列 2（$`= (1,4,3)`$ の末列 `0, 1←c0@0, ω←c0@0`）の $`[0, ω)`$ の頂上で、$`h_q = 1`$。$`H = 1 + 2 - 0 = 3`$。行 0〜3 に根の行を写す。父の列はどれも $`φ_1(x-1) = 3`$ である。
- $`j = 1`$ の子（水準 2、場合 3）：行 $`ω`$ に根の行の写し（父の列 3）、行 $`ω+1`$ に源 $`(2,1)`$ の持ち上げ（父の列 2）。
- $`j = 2`$ の子（水準 2）：源の段 $`[ω, ω \cdot 2)`$ を行き先の段 $`[ω \cdot 2, ω \cdot 3)`$ へ写す。この段には根の列の節点が無いので、上がらない（場合 1）。行 $`ω \cdot 2`$ に源 $`(2, ω)`$ を写す。
- 結果は `0, 1←c3@0, 2←c3@1, 3←c3@2, ω←c3@2, ω+1←c2@ω, ω·2←c2@ω`。01-feasibility §2.3 の公式の列 4 と同じである。すき間の高さ 3 は、世代の数 $`g = 2`$ と $`h_q = 1`$ の和で決まる。

## 3. 規則の読み方

- **場合 1**（上がらない）：帯の段を同じ高さへ写す。父の列は $`φ_i`$ で移す。Phyrion 氏の平行移動（translation）に当たる。
- **場合 2 の持ち上げの段**：根の高さより上の段を、$`Δ = (h_κ - h_ρ) i`$ 段だけ上へ写す。輪郭（contour）に当たる。
- **根の行の写し**（$`C ≠ ⊥`$ の項目）：すき間の段に、根の行 $`\mathrm{row}(ρ)`$ を何度も写す。水準 1 では、父の列は「根の行での列 $`x`$ の節点の父の列」の像である。最下行では、ひとつ左の列の像である。これが公式の magma（充填）である。
- **場合 3、場合 4**：写した帯の中で、さらに下の水準の帯を写す。持ち上げの量とすき間の高さは、ひとつ前の区画の境界の列 $`q`$ の高さ $`h_q`$ から測る。場合 4 のすき間の高さには、根の行での世代の数 $`g`$ が入る。

## 4. Phyrion 氏の weak の規則との違い

weak の規則は [Build.lean](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean/blob/main/OmegaY/Expansion/Build.lean) の `expandDiagram` である。

| 部品 | weak（Build.lean） | 公式（§2） |

## 5. 残っていた 9 回の食い違い

01-feasibility §2.5 で R が合わなかった 9 回は、次の 3 つの式の $`n = 1, 2, 3`$ である。

- $`(1,3,2,5,7,12,19,25,30)`$
- $`(1,4,2,6,8,14,21,32,37)`$
- $`(1,4,2,6,8,14,21,32,38)`$

原因は、§4 の表の 2 行目（持ち上げる節点）の違いである。次の性質を Q とする。

- 根の行を含む水準 2 の帯 $`F`$ が、$`τ`$ より下にある（$`F`$ は下の帯の段になる）。
- $`ρ = \mathrm{top}_F(c_r)`$ として、$`h_κ \gt h_ρ \gt 0`$。
- ある列 $`x`$（$`c_r \lt x \lt x_0`$）が参照の行 $`\mathrm{row}(ρ) - 1`$ で上がる。しかし、列 $`x`$ の行 $`\mathrm{row}(ρ)`$ の節点は、行 $`\mathrm{row}(ρ)`$ の中の祖先で根の列に届かない。

標準形の標本 S1〜S3（重複を除いて 10051 式）で Q を満たす式は、ちょうどこの 3 つである（[reference/official/ascension-gap.cjs](../reference/official/ascension-gap.cjs)）。

**例：$`(1,3,2,5,7,12,19,25,30)[1]`$ の列 11（列 7 の写し）.** 根は $`(4, 2)`$、$`τ = ω`$、$`w = 4`$。

- $`M(s)`$ の列 7 は `0, 1←c6@0, 2←c5@1`、列 8 は `0, 1←c7@0, 2←c4@1, 3←c4@2, ω←c4@2` である。
- 帯 $`F = [0, ω)`$ で、$`h_ρ = 2`$、$`h_κ = 3`$、$`Δ = 1`$。
- 参照の行 1 で、$`(7,1) → (5,1) → (4,1)`$ と根の列に届く（$`(7,2)`$ の父が $`(5,1)`$、$`(5,2)`$ の父が $`(4,1)`$）。列 7 は上がる。
- 行 2 の節点 $`(7,2)`$ は、上に節点が無いので $`P`$ が無い。行 2 の中では根に届かない。
- 公式：場合 2 で、段 2 と段 3 に根の行を写す。父の列はどちらも $`φ_1(5) = 9`$。列 11 は `0, 1←c10@0, 2←c9@1, 3←c9@2`、値は 69。
- weak：列 7 の marker は $`(7,0)`$ と $`(7,1)`$ である。$`(7,2)`$ は、同じ行の辺で根の列に届かないので marker でない。marker $`(7,1)`$ の参照の行は、境界の列 8 で行 2 より下の最も高い節点の行 1 である。持ち上げは 0 で、$`(7,2)`$ は行 2 に写る。列 11 は `0, 1←c10@0, 2←c9@1`、値は 61。

つまり、公式は「参照の行で上がる列は、根の高さ以上の段をすべて持ち上げる」。weak は「同じ行の辺で根の列につながる節点の上だけを、その行の参照の分だけ持ち上げる」。2 つが違うのは、根の高さの節点が、行の中では根につながらず、ひとつ下の行でつながる場合である。

01-feasibility §2.5 では、公式が $`(1,4,2,6,8,14,21,32,37)[1]`$ の列 10 に置く行 3 の節点を「世代の数」で説明しようとした。実際には、この節点は場合 2 の根の行の写し（段 3）である。世代の数は場合 4 でだけ使われる。

## 6. 試験

### 6.1 方法

[reference/official/check.cjs](../reference/official/check.cjs) で、各展開 $`s[n]`$ について次を確かめた。

- (a) 規則で組み立てた山が、出力の列の正準の山と一致する（全節点の行と父）。
- (b) $`s[n] \lt s`$（辞書式）。
- (c) 値が公式のプログラムの出力と一致する。公式のプログラムは値を浮動小数点で扱うので、公式の値が $`2^{53}`$ 以上になる展開は (c) から外した。

末項が 1 の式は除いた（末項を消すだけで、写しが無い）。

## 7. 限界

- 標本は有限である。値と長さに上限がある。規則の正しさの根拠は、この差分試験だけである。公式の定義はプログラムしか無い。
- 公式の値が $`2^{53}`$ を超える展開は、値の比較から外した（計 188 回）。自前の実装は整数（BigInt）で計算する。
- 「起こらない場合」（§2.4）は、試験では一度も起こらなかった。標準形でこれらが起こらないことは、証明していない。
- 公式のプログラムの設定「leg-based test for ascension」（既定では切れている）は扱っていない。入れると $`A(S,x)`$ の判定が変わる。
