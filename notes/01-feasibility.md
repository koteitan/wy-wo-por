使った出典：

- weak ω-Y：Phyrion 氏の [omega-Y-Well-Ordering-Lean](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean)（コミット `33c16a8`、Apache-2.0）の [reference/engine.js](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean/blob/main/reference/engine.js) と Lean の文。
- Lean は検査していない（`lake build` も `leanman` も走らせていない）。定理の文と docs を読んだだけである。

## 0. 要約

- **食い違いの原因は magma（充填）の規則だけである。** 写した区画の中で、持ち上げた部分と持ち上げない部分の間の「すき間」を埋める節点の父が違う。
  - weak：すき間の節点の父は、みな 1 本の列にある。それは制御の辺（marker からその上の節点への辺）の父の列の像である。すき間を縦に写す。
  - 公式：すき間は、根の行（根の列の中で同じ段の、最も高い節点の行）の横の構造を写す。すき間の節点の父は、その行の左の脚の列の像にある。最下行なら、ひとつ左の列である。
  - 公式の展開を「weak の規則で、充填（すき間の節点とその父）だけを公式の規則に替えたもの」で再現した。標準形からの展開 40527 回のうち 40518 回で完全に一致した。残る 9 回は、公式がすき間を weak より高く積む場合である（§2.5）。
- **不変量の試験（公式の展開、標準形 40527 回）：**
  - 成り立つもの：次元 $`D`$ の保存、構成した山と出力の正準の山の一致、列の中の鍵の狭義増加、減一の分類、辞書式の減少。
  - 成り立たないもの：複写辺の鍵の上界（`ActualCopiedKeyBound`）。破れるのは 1495 回で、公式と weak が食い違う展開とちょうど一致する。最小の反例は $`(1,3,3)[2]`$ である。
  - 「充填辺の鍵 < 制御辺の鍵」は、鍵の不等式としては成り立つ。しかし証明が必要とする「父の列が同じ」が破れる（5129 本の辺）。
- **判断：Phyrion 氏の方法は、そのままでは公式の ω-Y に移せない。** 証明の核は、新しい辺の関係を「同じ端点の列を持つ古い辺の関係を、鍵を下げて写す」ことで得る段である。公式の magma の辺には、写す元の古い辺が無い（型 A）か、あっても鍵が小さすぎる（型 B）。行、山、鍵、反映の意味の層、次元の保存、再構成の文は使い回せる。変える必要があるのは、表現が持つ関係の集合と、写した列にラベルを与える仕方である。これは新しい数学で、成り立つかは分からない（§4）。

## 1. 記法と実験の設定

### 1.1 記法

- 行は $`ω^ω`$ 未満の順序数で、最下行を 0 とする（Phyrion 氏の表示の行）。
- 列 $`c`$ の節点 $`u`$ と、その真上の節点 $`u^+`$ の間の辺を $`e = (u, u^+)`$ と書く。$`u^+`$ に記録された左の端点を、辺の父 $`π(e)`$ とする。父はいつも $`c`$ より左の列にある。
- 行の規則：$`\mathrm{row}(u^+) = \mathrm{row}(u) + ω^{j}`$。和は順序数の和である。父と $`u`$ が同じ行なら $`j = 0`$。そうでなければ、$`\mathrm{row}(π)`$ と $`\mathrm{row}(u)`$ の係数が違う最も高い指数を $`i`$ として、$`j = i + 1`$ である。この $`j`$ を跳び $`\mathrm{jump}(\mathrm{row}(u), \mathrm{row}(π))`$ と書く。
- $`s = (s_0,…,s_x)`$、その山を $`M(s)`$ とする。根 $`r`$ は、列 $`x`$ の一番上の節点の父である。根の列を $`c_r`$、幅を $`w = x - c_r`$ とする。
- 減一：$`s'`$ は $`s_x`$ を 1 減らした列である。
- 区画 $`b`$（$`b ≥ 1`$）の列 $`c_r + bw + o`$（$`1 ≤ o ≤ w`$）は、$`M(s')`$ の列 $`y = c_r + o`$ の写しである。$`o = w`$ の列を境界の列、$`o \lt  w`$ の列を普通の列と呼ぶ（Phyrion 氏の用語）。
- 列の写像：$`φ_b(c) = c`$（$`c \lt  c_r`$）、$`φ_b(c) = c + bw`$（$`c ≥ c_r`$）。Lean の `copiedKeyColumn` と同じである。
- 鍵（[Geometry/MountainKeys.lean](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean/blob/main/OmegaY/Geometry/MountainKeys.lean) の `keyTemplate`）：尺度 $`k`$ の根 $`ρ_k(v)`$ は、行の跳びが $`k`$ 以下の父の辺だけを $`v`$ からたどった終点である。辺 $`e`$ の跳びを $`d = \mathrm{jump}(\mathrm{row}(u), \mathrm{row}(π(e)))`$ とすると、

```math
κ_D(e) = \bigl(\mathrm{col}\,ρ_D(π),\ \mathrm{col}\,ρ_{D-1}(π),\ …,\ \mathrm{col}\,ρ_d(π),\ ⊤,\ …,\ ⊤\bigr)
```

  である。比較は辞書式で、$`⊤`$ が最大である。列の番号をそのままラベルとして使う（Lean の `templateKey` と同じ比較である）。

### 1.2 プログラムと標本

- N：公式（Naruyoko 氏）。P：weak（Phyrion 氏の engine.js）。R：P の充填の部分だけを §2.2 の規則に替えた、自前の再実装。
- 山は、自前で書いた正準の山の構成で作った。Phyrion 氏の `makeMountain` と同じ規則である。
- 展開のコピー数は $`n ∈ \{1,2,3\}`$。末項が 1 の式は除いた（削除だけで、写しが無いため）。

| 標本 | 作り方 | 式 | 展開 |
|---|---|---:|---:|
| S1 | $`(1,2),(1,3),(1,4)`$ から N で幅優先。接頭辞は長さ 7 以下、値 200 以下 | 4000 | 11373 |
| S2 | $`(1,5),(1,6)`$ から N で幅優先。長さ 8 以下、値 400 以下 | 8000 | 23106 |
| S3 | N の子孫を乱歩で集めた。種は $`(1,3),(1,4),(1,5),(1,3,3),(1,4,4),(1,4,5),(1,4,8),(1,4,20),(1,4,4,4)`$。長さ 9 以下、値 5000 以下 | 2131 | 6048 |

## 2. 食い違いを生む規則（課題 1）

### 2.1 写した列の 3 種類の節点（weak）

engine.js と [Expansion/Build.lean](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean/blob/main/OmegaY/Expansion/Build.lean) を読んでまとめる。区画 $`b`$ で源の列 $`y`$ を写すとき、marker（根の列から「下端と父が同じ行の辺」の道でつながる節点）$`m`$ ごとに、次の 3 種類の節点を置く。

1. 平行移動（translation）：行 $`\mathrm{row}(m)`$ に置く。父は、源の父の列の像の中で、それより下の最も高い節点である。
2. 輪郭（contour）：$`m`$ より上の源の節点を持ち上げて置く。持ち上げた先の最初の行は、参照の行 $`g`$（直前の境界の列から読む）の次である。父は源の父の像である。
3. 充填（fill、magma）：行 $`[\mathrm{row}(m), g]`$ のすき間を埋める。

weak の充填：制御の辺 $`(m, m^+)`$ の父を $`p`$ とする。列 $`φ_b(\mathrm{col}\,p)`$ の節点 $`q`$ で $`\mathrm{row}(m) ≤ \mathrm{row}(q) \lt g`$ のものすべてについて、行 $`\mathrm{row}(q) + ω^{j}`$（$`j = \mathrm{jump}(q, q^+) - 1, …, 0`$）の節点を置き、父を $`q`$ にする。すき間の節点の父は、みな同じ列 $`φ_b(\mathrm{col}\,p)`$ にある。

### 2.2 公式の充填

平行移動と輪郭は、公式でも同じである（§2.4 の再実装で確かめた）。違うのは充填である。公式の規則を、プログラムの動きから次のように書き起こした。

- 副根：すき間の行 $`ρ`$ に対して、根の列の節点のうち、行が $`\mathrm{row}(r)`$ 以下で、$`ρ`$ と指数 1 以上の係数（ω の部分）が等しいものの中で、最も高いものを $`z_0`$ とする。無ければ $`ρ`$ の代わりに $`\mathrm{row}(m)`$ で探す。
- $`z`$：$`M(s')`$ の列 $`y`$ の、行 $`\mathrm{row}(z_0)`$ の節点。
- 左の脚 $`ℓ(z)`$：$`z`$ の下から $`z`$ への辺の父の列。$`z`$ が最下行なら $`ℓ(z) = y - 1`$。
- すき間の積み方：平行移動の節点 $`t_0`$（行 $`\mathrm{row}(m)`$）から始める。列 $`φ_b(ℓ(z))`$ の中で行が $`\mathrm{row}(t_i)`$ 以下の最も高い節点を $`p_i`$ とする。次の節点 $`t_{i+1}`$ を、山の行の規則で行 $`\mathrm{row}(t_i) + ω^{j}`$ に置き、父を $`p_i`$ にする。行が $`g`$ に着いたら止める。

言いかえると次のとおりである。

- weak：すき間は、制御の辺の父の列を縦に写したものである。
- 公式：すき間は、根と同じ段の行（副根の行）の横のつながりを写したものである。その行で $`y`$ の左の脚だった列の像を父の列にして、山の規則で積む。最下行では、左の脚はひとつ左の列 $`y-1`$ である。

2 つが一致するのは $`ℓ(z) = \mathrm{col}\,p`$ のときである。食い違う場合、公式の父は weak の父より右の列にある（§2.4）。標準形の食い違う展開 1495 回のすべてで、最初に違う項は公式の方が大きかった。

### 2.3 例

行は最下行を 0 とする。「$`k←c_j@h`$」は、行 $`k`$ の節点で、その下からの辺の父が列 $`j`$ の行 $`h`$ にあることを表す。

**$`(1,3,3)[2]`$。** 公式 $`(1,3,2,5,7,12)`$、weak $`(1,3,2,5,4,9)`$。

- 根は $`c_0@0`$、$`w = 2`$、$`s' = (1,3,2)`$。$`M(s')`$ の列 2 は `0, 1←c0@0` である。
- 区画 1 の列 4 は、列 2 の写しである。行 0 は平行移動、行 1 はすき間、行 2 は輪郭（父 $`c_2@1`$）である。
- weak：制御の辺（列 2 の $`0→1`$）の父は列 0 で、像は列 2。すき間の節点は `1←c2@0`。
- 公式：副根の行は最下行、$`z = c_2@0`$、$`ℓ(z) = 1`$、像は列 3。すき間の節点は `1←c3@0`。
- 値は上から $`v(u) = v(u^+) + v(π)`$ で決まる。列 4 の値は、weak で $`2 + v(c_2@0) = 2 + 2 = 4`$、公式で $`2 + v(c_3@0) = 2 + 5 = 7`$ である。

**$`(1,3,4,3)[2]`$。** 公式 $`(…,5,9,11,…)`$、weak $`(…,5,9,4,…)`$。根は $`c_0@0`$、$`w = 3`$。

- 列 5（列 2 の写し）：制御の父は列 1 で、$`ℓ(z) = 1`$ と一致する。両方とも `1←c4@0`。
- 列 6（列 3 の写し）：制御の父は列 0 で、像は列 3。$`ℓ(z) = 2`$ で、像は列 5。weak `1←c3@0`、公式 `1←c5@0`。

**$`(1,3,8,13)[2]`$。** 公式 $`(…,21,34,56)`$、weak $`(…,21,29,46)`$。根は $`c_1@1`$（最下行ではない）、$`w = 2`$。

- 列 5（列 3 の写し）の行 2 の節点が違う。
- weak：父 $`c_3@1`$（根の像）。
- 公式：副根の行は行 1、$`z = c_3@1`$。$`z`$ の下の辺の父は列 2 で、像は列 4。父は $`c_4@1`$。

**$`(1,4,4)[2]`$。** すき間の行の集合も違う例である。公式 $`(1,4,3,11,34,101)`$、weak $`(1,4,3,11,10,38)`$。

- 公式の列 4：`0, 1←c3@0, 2←c3@1, 3←c3@2, ω←c3@2, ω+1←c2@ω, ω·2←c2@ω`
- weak の列 4：`0, 1←c2@0, 2←c2@1, ω←c2@1, ω+1←c2@ω, ω·2←c2@ω`
- 公式は列 3 に沿って積むので、列 3 の高さ（行 0〜2）の分だけ段が増える。weak は列 2 に沿って積む。

### 2.4 検証

  - S3 の 350 回のうち 344 回で同じ形だった。残る 6 回は、weak に無い節点を公式が置く形だった（§2.5）。

|---|---:|---:|---:|
| S1 | 11373 | 11373 | 10852 |

- 父の列だけを替え、すき間の行の集合は weak のままにした版では、S1 と S2 は全部一致した。S3 は 5976 回だった。$`(1,4,4)[2]`$ のように、すき間の高さの違いが S3 で初めて現れる。

### 2.5 まだ書き起こせていない部分

S3 の 9 回（3 つの式、それぞれ $`n = 1,2,3`$）は R でも一致しない。例は $`(1,4,2,6,8,14,21,32,37)[1]`$ である。列 10 で、weak にはすき間が無い。公式は、その列に行 3 の節点を 1 つ多く置く（`3←c9@2`）。公式のプログラムでは、すき間の高さは副根の行の中での $`y`$ の世代の数（左の脚を根の列まで何回たどるか）で決まる、と読める。R はこれを写していない。規則の完全な書き起こし（00-survey の §4.2 手順 1〜2）には、この部分が要る。

### 3.1 I3 の中身と、破れ方

I3 は次の主張である。出力の山の辺 $`e`$ で、下端の列が $`c = c_r + bw + o \gt  x`$ のものについて、$`M(s')`$ の列 $`y = c_r + o`$ に辺 $`e'`$ があり、

```math
\mathrm{col}\,π(e) = φ_b(\mathrm{col}\,π(e')),\qquad κ_D(e) ≤ φ_b\bigl(κ_D(e')\bigr).
```

これがあると、反映の模型で `Model.key_weaken`（同じ 2 つのラベルの間で、大きい鍵の関係から小さい鍵の関係が出る）が使える。写した列が古いラベルをそのまま使うので、新しい辺の関係が古い辺の関係から出る。

公式での結果：

- I3 が破れる展開は、公式と weak が食い違う展開とちょうど一致した（S1 で 521 回、S2 で 624 回、S3 で 350 回）。S4 でも 1838 回で一致した。weak では I3 が常に成り立つ（Phyrion 氏の定理。S1〜S3 でも全部成り立った）。
- 破れる辺は、境界の列にも普通の列にもある（S1+S3：境界 1684 本、普通 3520 本）。普通の列の最小の例は $`(1,3,3,3)[1]`$ の列 5 である。
- 破れ方は 2 つの型に分かれる（S1〜S3）。

| 型 | 内容 | 辺 | 展開 | 最小の例 |
|---|---|---:|---:|---|

- 型 A は、副根の行が最下行のときに起こる。左の脚 $`y-1`$ は辺ではなく、最下行で隣り合っていることにすぎない。
- 型 B は、副根の行の中の辺（$`z`$ の下の辺）を、すき間の高い位置へ写すときに起こる。I5 により、同じ列で高い辺ほど鍵が大きい。低い辺の鍵では、高い位置の辺の鍵を抑えられない。

### 3.2 I4 について

- weak（S1+S3）：198217 本の充填辺のすべてで、鍵 < 制御辺の鍵、かつ父の列が同じだった。
- 公式（R = N の展開だけ）：198781 本のすべてで、鍵 < 制御辺の鍵だった。これは I5 と I2 から自動的に出る。しかし 5129 本で、父の列が制御辺の父の列と違った。
- 最小の例は $`(1,3,3)[2]`$ の列 4 である。充填辺 $`0→1`$ の父は列 3、鍵は $`(0,0)`$。制御辺 $`1→2`$ の父は列 2、鍵は $`(2,2)`$。
- `key_weaken` は同じ端点のラベルの間でしか使えない。父の列が違うと、鍵が小さくても関係を運べない。

### 3.3 親のグラフの形

- I2 が成り立つので、公式の出力の山は正準の山である。父が左にあること、父の上界（father upper bound）、`Normal` の局所的な証明書など、正準の山について Lean で示された性質はそのまま成り立つ。
- 違うのは出どころの形である。weak では、すき間の辺は 1 本の列（制御の父の列の像）に集まる。公式では、すき間の辺は副根の行の横のつながりに沿って、区画の中の列（多くは $`c-1`$）を指す。

## 4. 方法を移せるか（課題 3）

### 4.1 そのまま、または文だけ使えるもの

- 行の算術、正準の山、鍵、尺度の根、強い V（`Rows`、`Canonical`、`Geometry`、`Keys`）。山の定義は公式と同じである（I7）。
- 反映の意味の層（`Model`、`Reflection`）。これは鍵の構文と単調性しか使わない。
- 減一の分類（I6）。展開の規則に依らない。
- 次元の保存（I1）と再構成（I2）。文は公式でも成り立つ。ただし Lean の証明は weak の実行の定義についてのものなので、公式の規則を形式化してから証明し直す必要がある。公式のすき間は参照の行 $`g`$ で止まるので、I1 の証明はあまり変わらない見込みである（推測）。
- 最後の順序数の帰納法（`ActualRepresentationDescent`、`WellFounded`）の枠。

### 4.2 壊れるもの

Phyrion 氏の降下の段（[FINAL-DESCENT-AUDIT.md](https://github.com/Phyrion1343/omega-Y-Well-Ordering-Lean/blob/main/docs/FINAL-DESCENT-AUDIT.md) の §1、§4）は次の形である。

1. 出力の新しい辺は、どれも減一の山の本物の辺を $`φ_b`$ で写したもので、鍵は写した鍵以下である（I3）。充填辺は、同じ列を端点に持つ制御辺を経由してこれに帰着する（I4）。
2. 反映では、写した列は古いラベルをそのまま使う。新しい辺の関係は、古い関係から `key_weaken` で出る。

公式では 1 が、食い違うちょうどその展開で偽になる（§3.1）。

- 型 A の辺には、古い表現の中に、2 つのラベル $`f(y-1), f(y)`$ の間の関係が何も無い。ラベルを使い回す限り、この関係は出てこない。
- 型 B の辺では、関係はあるが鍵が小さすぎる。

したがって `ActualFillCopiedKey`、`ActualCopiedKeyBound`、`ActualSpliceRepresentation`、`Splice/IteratedReservoirs` の役割は、そのままでは果たせない。weak の証明の 8.3 万行のうち、magma と複写の鍵の運搬に関わる部分（`Actual*Copied*`、`ActualFill*`、境界の分類の多く）は作り直しになる。

### 4.3 変える必要があるもの（案）

どれも確かめていない。

- (i) **横の関係の予備を表現に入れる.** 表現の不変量に、根の各段の行 $`Z`$ に沿った関係 $`R(θ, f(ℓ_Z(y)), f(y))`$ を加える。鍵 $`θ`$ は、後ですき間の辺が要求する鍵以上でなければならない。最下行では、隣り合う列 $`f(y-1), f(y)`$ の関係になる。これは正準の山の辺としては記録されていない。展開のたびに、出力の表現がこの予備をまた持つこと（予備の保存）を示す必要がある。これが核の新しい仕事である。
- (ii) **写した列に新しいラベルを選ぶ.** 古いラベルを使い回すのをやめる。区画ごとに、すき間の辺も要求に含めた大きな図式を反映して、新しいラベルを選ぶ。関係を「運ぶ」のでなく「作る」ことになる。Σ₁ 初等性の意味の層（wmwy-wo-por の v0.1.1 が使う）なら、「$`a ≺ c`$ かつ $`b ≺ c`$ かつ $`a \lt b`$ なら $`a ≺ b`$」のような導出が使える。ただし、そのための共通の上端 $`c`$ が古い表現にあるかは分からない。$`(1,3,3)`$ では、列 1 と列 2 の両方の上にある関係は、古い図式に無い。
- (iii) **鍵または意味の読み替え.** 公式の系では、列 $`(1,3,2,5,4,9,8,17,…)`$ の上限は $`(1,3,2,5,5)`$ である（00-survey §1.6）。公式の $`(1,3,3)`$ はそれより上にあり、その基本列は $`(1,3,2,5,7,12,…)`$ である。weak の系では、同じ列 $`(1,3,2,5,4,9,8,17,…)`$ が $`(1,3,3)`$ の基本列である。つまり公式では、最下行で等しい値が並ぶこと（$`(…,3,3)`$）が、それだけで行 1 の関係の材料になる。行の中の横の親の構造（1 次元の部分山の親）を鍵や図式の言語に入れる、別の意味づけが要るかもしれない。

別の道として、weak との比較も考えた。公式の標準形がみな weak の標準形なら、Phyrion 氏の `omegaY_generated_isWellOrder`（weak の生成域は辞書式で整列）と、公式の辞書式の減少から、停止性がすぐ出る。しかしこれは偽である見込みが高い。$`(1,3,2,5,5)`$、$`(1,3,2,5,7)`$、$`(1,3,3,2,5,8)`$ などは、公式では $`(1,4)`$ から貪欲な降下で届く。weak の貪欲な降下は $`(1,3,3)`$ などで止まり、届かない。順序を保つ別の翻訳写像があるかは分からない。

### 4.4 判断

- 組合せの層の中心の段（I3、I4）が、公式と weak が食い違う展開でちょうど破れる。最小の反例 $`(1,3,3)[2]`$ はとても小さい。したがって、Phyrion 氏の証明を「展開の定義を差し替えて、壊れたモジュールを直す」形（00-survey §4.2 の手順 6）で移すのは、見込みが低い。
- 一方で、公式の展開は、試したすべてで辞書式に下がり（47727 回）、次元を保ち、構成した山が正準の山と一致した。停止しないことを示す手がかりは見つからなかった。
- 移すには、少なくとも §4.3 の (i) か (ii) の新しい考えが要る。それは「写した列が、古い表現に無い関係を持つ」ことを扱う反映の段である。これは未解決の数学の仕事で、規模は weak の証明の magma の部分を作り直す以上になる。

## 6. 限界

- 標本は有限である。S1〜S3 は標準形の一部で、値と長さに上限がある。「最小の反例」は、この標本の中で（長さ、和、$`n`$）の順に最小という意味である。S4（合法な列の全部、長さ 5 以下、項 7 以下）でも、最小の食い違いは $`(1,3,3)[2]`$ だった。
- §2.2 の規則は、公式のプログラムの動きからの書き起こしで、R による再現で確かめただけである。公式の定義はプログラムしか無いので、これ以上の根拠は無い。
- 鍵の比較は、列の番号をラベルとした比較（`templateKey`）で行った。任意の狭義増加なラベル付けでも、同じ不等式が成り立つ。I3 の反例は、端点の列が合わない（型 A）か、列の番号の比較で鍵が大きい（型 B）ので、ラベルの選び方で救えない。ただし、Phyrion 氏の証明の別の段（予備 $`F_b`$、$`T_b`$ など）で救える可能性は、この試験では調べていない。
- 公式のプログラムは値を浮動小数点で扱う。値が $`2^{53}`$ を超える展開は、比較から外すべきである（S4 の 1 回）。
