# 整礎関係と整礎再帰

前提

| ノート | ここで使う言葉 |
|---|---|
| [01 順序数と ω₁](01-ordinals.md) | 順序数、無限降下列、ラベル $`\{o \mid o \le \omega_1\}`$、$`\{0, \ldots, n-1\}`$ |

このノートは 3 つのことを説明する。整礎関係、整礎再帰、ラベルが下がることによる停止である。関係 $`R`$ の定義（[07](07-relation-r.md)）は §4 と §5 の形をしている。停止性の証明の全体（[06](06-combinatorial-layer.md)）は §6 の形をしている。

## 1. 整礎関係

**定義（整礎）.** 集合 $`X`$ の上の関係 $`\prec`$ が **整礎** であるとは、$`X`$ の空でない部分集合 $`S`$ がどれも $`\prec`$-極小元を持つことをいう。極小元とは、$`y \prec x`$ となる $`y \in S`$ が無い $`x \in S`$ のことである。

整礎であることと、$`x_0 \succ x_1 \succ x_2 \succ \cdots`$ となる無限降下列が無いことは同値である。「無限降下列が無いなら整礎」の向きには、選択公理の弱い形（従属選択）を使う。

**定義（到達可能）.** $`X`$ の部分集合 $`Q`$ を、次の条件で閉じた最小の集合とする。

```math
\bigl(\forall y \prec x\ \ y \in Q\bigr) \implies x \in Q
```

$`x \in Q`$ のとき、$`x`$ は **到達可能** であるという。言いかえると、$`x`$ が到達可能であるとは、$`y \prec x`$ となるすべての $`y`$ が到達可能であることである。$`y \prec x`$ となる $`y`$ が無い $`x`$ は、到達可能である。

**性質.** $`\prec`$ が整礎であることと、すべての $`x \in X`$ が到達可能であることは同値である。

**証明.**

- 整礎なら：到達可能でない元の集合 $`S`$ が空でないとする。その極小元 $`x`$ を取る。$`y \prec x`$ なら $`y \notin S`$ なので、$`y`$ は到達可能である。よって $`x`$ も到達可能で、$`x \in S`$ に反する。
- すべて到達可能なら：$`S`$ を極小元の無い部分集合とする。$`X \setminus S`$ は上の条件で閉じている。$`y \prec x`$ となる $`y`$ がどれも $`S`$ に無いのに $`x \in S`$ なら、$`x`$ は $`S`$ の極小元になるからである。$`Q`$ は閉じた最小の集合なので、$`Q \subseteq X \setminus S`$ である。$`Q = X`$ なので $`S`$ は空である。$`\square`$

| 関係 | 整礎か |
|---|---|
| $`\mathbb N`$ の $`\lt`$ | はい |
| 順序数の $`\lt`$、ラベルの $`\lt`$ | はい |
| $`\mathbb Z`$ の $`\lt`$ | いいえ |
| 有限列の全体の辞書式順序 | いいえ |

**定義（有限列の辞書式順序）.** 整数の有限列 $`s, t`$ を、最初に違う項の大小で比べる。一方が他方の真の先頭部分（接頭辞）なら、短い方が小さい。これを **辞書式順序** と呼ぶ。

**例.** 次の列は辞書式順序の無限降下列である。最初に違う項は、左の列では $`2`$、右の列では $`1`$ だからである。先頭の 5 項は Python で確かめた。

```math
(1,2) \gt (1,1,2) \gt (1,1,1,2) \gt (1,1,1,1,2) \gt \cdots
```

したがって、辞書式順序は有限列の全体の上では整礎でない。各項の順序が整礎でも、長さに上限が無いと整礎にならない。あとのノートの停止性の証明は、辞書式順序ではなく §6 の方法を使う。

## 2. 整礎帰納法

**定理（整礎帰納法）.** $`\prec`$ が整礎で、性質 $`P`$ が次を満たすとする。

```math
\forall x\ \Bigl(\bigl(\forall y \prec x\ \ P(y)\bigr) \implies P(x)\Bigr)
```

このとき、すべての $`x`$ で $`P(x)`$ が成り立つ。

**証明.** $`P`$ が偽になる $`x`$ の集合が空でないとする。その極小元 $`x`$ を取る。$`y \prec x`$ なら $`P(y)`$ は真である。仮定から $`P(x)`$ も真になり、矛盾する。$`\square`$

## 3. 辞書式積と鍵の順序

**定義（辞書式積）.** $`(A, \lt_A)`$ と $`(B, \lt_B)`$ に対し、$`A \times B`$ の **辞書式順序** を次で定める。

```math
(a, b) \prec (a', b') \iff a \lt_A a' \ \lor\ (a = a' \land b \lt_B b')
```

**定理.** $`\lt_A`$ と $`\lt_B`$ が整礎なら、辞書式順序も整礎である。

**証明.** $`a`$ についての整礎帰納法の中で、$`b`$ についての整礎帰納法をして、$`(a, b)`$ が到達可能であることを示す。$`(a, b)`$ より小さい組は、$`a' \lt_A a`$ の組（外側の帰納法の仮定で到達可能）か、$`a`$ が同じで $`b' \lt_B b`$ の組（内側の帰納法の仮定で到達可能）である。§1 の性質から整礎である。$`\square`$

**例.** $`\mathbb N \times \mathbb N`$ で、$`(1, 0)`$ より小さい組は $`(0, 0), (0, 1), (0, 2), \ldots`$ と無限個ある。それでも降下列はどれも有限である。例えば $`(1,0) \succ (0, 100) \succ (0, 99) \succ \cdots \succ (0, 0)`$ は 102 項で止まる（Python で数えた）。

**定義（鍵）.** $`m`$ を自然数とする。**$`\top`$** はラベルでない新しい元で、どのラベルよりも大きいとする。$`\omega_1`$ はラベルなので、$`\omega_1 \lt \top`$ である。長さ $`m`$ の **鍵** は、ラベルか $`\top`$ を $`m`$ 個並べた列 $`K = (K_0, \ldots, K_{m-1})`$ である。鍵の集合を $`\mathrm{Key}_m`$ と書く。

```math
\mathrm{Key}_m = \bigl\{\, K \mid K : \{0, \ldots, m-1\} \to \mathrm{Label} \cup \{\top\} \,\bigr\}
```

鍵の $`k`$ 番目の元 $`K_k`$ を **座標** $`k`$ と呼ぶ。2 つの鍵は、**最初に違う座標** で比べる。

```math
K \lt K' \iff \exists k\ \bigl(K_k \lt K'_k \ \land\ \forall j \lt k\ \ K_j = K'_j\bigr)
```

座標がすべて $`\top`$ の鍵 $`(\top, \ldots, \top)`$ が、$`\mathrm{Key}_m`$ の最大の元である。

次の表は Python で確かめた。

| 比べる 2 つの鍵（$`m = 2`$） | 結果 | 理由 |
|---|---|---|
| $`(3, 5)`$ と $`(3, \top)`$ | $`(3, 5) \lt (3, \top)`$ | 座標 0 が等しく、座標 1 で $`5 \lt \top`$ |
| $`(2, \top)`$ と $`(3, 0)`$ | $`(2, \top) \lt (3, 0)`$ | 座標 0 で $`2 \lt 3`$ |
| $`(\omega, 0)`$ と $`(5, \top)`$ | $`(5, \top) \lt (\omega, 0)`$ | 座標 0 で $`5 \lt \omega`$ |

**定理（鍵の順序は整礎）.** $`\mathrm{Key}_m`$ の順序は整礎である。

**証明.** $`\mathrm{Label} \cup \{\top\}`$ は整礎である。降下列は $`\top`$ を高々最初の項に 1 回含み、残りはラベルの降下列だからである。長さ $`m`$ の列を最初に違う座標で比べる順序は、上の辞書式積を $`m - 1`$ 回くり返したものと同じ順序である。よって整礎である。$`\square`$

**定義（段と上端）.** [07](07-relation-r.md) で、関係 $`R(\theta, a, b)`$ を定義する。$`\theta`$ は鍵、$`a`$ と $`b`$ はラベルである。その定義は、組 $`(b, \theta)`$ についての整礎再帰（§4）である。この組 $`(b, \theta)`$ を **段** と呼ぶ。段の 1 つめの成分 $`b`$ を **上端** と呼ぶ。段の順序 $`\lhd`$ は、ラベルの順序と鍵の順序の辞書式積である。

```math
(b', \kappa') \lhd (b, \theta) \iff b' \lt b\ \lor\ (b' = b \land \kappa' \lt \theta)
```

$`b', b`$ はラベル、$`\kappa', \theta`$ は鍵である。上の 2 つの定理から、$`\lhd`$ は整礎である。

次の表は Python で確かめた。

| 比べる 2 つの段（$`m = 2`$） | 結果 | 理由 |
|---|---|---|
| $`(5, (3, \top))`$ と $`(\omega, (0, 0))`$ | $`(5, (3, \top)) \lhd (\omega, (0, 0))`$ | 上端で $`5 \lt \omega`$ |
| $`(\omega, (0, \top))`$ と $`(\omega, (1, 0))`$ | $`(\omega, (0, \top)) \lhd (\omega, (1, 0))`$ | 上端が等しく、鍵の座標 0 で $`0 \lt 1`$ |

## 4. 整礎再帰

**定理（整礎再帰）.** $`\prec`$ を集合 $`T`$ の上の整礎関係とする。$`V`$ を値の集合とする。各 $`t \in T`$ と、「$`t`$ より小さい引数での値」を受け取って、$`t`$ での値を返す規則 $`G`$ があるとする。このとき、次を満たす関数 $`F : T \to V`$ がちょうど 1 つある。$`F{\restriction}X`$ は、$`F`$ を集合 $`X`$ に制限した関数である。

```math
F(t) = G\bigl(t,\ F{\restriction}\{t' \mid t' \prec t\}\bigr)
```

**証明の概略.**

- 1 つしかないこと：2 つの解 $`F, F'`$ について、$`F(t) = F'(t)`$ を $`t`$ についての整礎帰納法で示す。$`t`$ より小さいところで一致すれば、右辺が同じなので $`t`$ でも一致する。
- あること：「$`t' \prec t`$ かつ $`t \in U`$ なら $`t' \in U`$」を満たす部分集合 $`U`$ の上で等式を満たす関数を、部分解と呼ぶ。2 つの部分解は、両方が定義されたところで一致する（上と同じ帰納法）。部分解をすべて合わせると 1 つの関数になる。それが $`T`$ 全体で定義されていることを、整礎帰納法で示す。$`t`$ より小さい元がすべて定義されていれば、$`G`$ で $`t`$ での値を足した部分解が作れるからである。$`\square`$

**例（Ackermann 関数）.** 引数の組 $`(m, n)`$ の集合 $`\mathbb N \times \mathbb N`$ に、§3 の辞書式順序を入れる。

```math
\begin{aligned}
A(0, n) &= n + 1, \cr
A(m+1, 0) &= A(m, 1), \cr
A(m+1, n+1) &= A\bigl(m,\ A(m+1, n)\bigr).
\end{aligned}
```

右辺が呼ぶ引数 $`(m, 1)`$、$`(m+1, n)`$、$`(m, \cdot)`$ は、どれも左辺の引数より辞書式に小さい。だから整礎再帰で定義できる。

次の値は Python で計算した。

| $`A(m, n)`$ | $`n = 0`$ | $`n = 1`$ | $`n = 2`$ | $`n = 3`$ |
|---|---|---|---|---|
| $`m = 0`$ | 1 | 2 | 3 | 4 |
| $`m = 1`$ | 2 | 3 | 4 | 5 |
| $`m = 2`$ | 3 | 5 | 7 | 9 |
| $`m = 3`$ | 5 | 13 | 29 | 61 |

## 5. ガードつきの再帰

§4 の規則 $`G`$ は、$`t`$ より小さい引数での値だけを読める。[07](07-relation-r.md) の $`R`$ の定義では、どの段（§3）を読むかが、定義の中で動く変数の値で決まる。そのため、前もって「読む段が小さい」とは言えない。そこで次の 3 つの手順を取る。

1. 右辺で引数 $`t'`$ での値を読むところを、「$`t' \prec t`$ であり、かつ $`t'`$ での値が真」に置き換える。この条件 $`t' \prec t`$ を **ガード** と呼ぶ。$`t' \prec t`$ でないところでは、この式は偽になる。すると右辺は $`t`$ より小さい引数しか読まないので、§4 の定理で定義できる。
2. §4 の等式を得る。この段階では、右辺にガードが付いている。
3. 右辺が実際に読むところでは、ガードがいつも真であることを別に示す。するとガードを外した等式が得られる。

値が数のときは、ガードが偽の項を和から除く。

**小さい例.** $`\mathbb N`$ の上で $`F(n) := 1 + \sum_{i \in S_n} F(i)`$ という形の定義を考える。$`S_n`$ は $`n`$ ごとに与えた有限集合で、$`n`$ 以上の数を含むかもしれない。そのため、このままでは整礎再帰にならない。ガードつきで次のように書けば、整礎再帰で定義できる。

```math
F(n) := 1 + \sum_{i \in S_n,\ i \lt n} F(i)
```

$`S_n \subseteq \{0, \ldots, n-1\}`$ が別に示せれば、ガードを外した式 $`F(n) = 1 + \sum_{i \in S_n} F(i)`$ が成り立つ。

たとえば $`S_n = \{\lfloor n/2 \rfloor, n\}`$ とする。ガードつきの定義の値は、$`n = 0, \ldots, 7`$ で $`1, 2, 3, 3, 4, 4, 4, 4`$ である（Python で計算した）。この $`S_n`$ は $`n`$ を含む。ガードを外した式 $`F(n) = 1 + F(\lfloor n/2 \rfloor) + F(n)`$（$`n \ge 1`$）を満たす $`F`$ は無い。この例では、ガードは外せない。

## 6. ラベルの上界による停止

状態の集合 $`X`$ の上の 1 歩の関係 $`\to`$ が整礎であることを、整礎な順序 $`(L, \lt)`$ の元（ラベル）で示す。$`s \to t`$ は「$`s`$ から 1 歩で $`t`$ に進む」と読む。$`\to`$ が整礎であるとは、逆向きの関係 $`t \leftarrow s`$ が §1 の意味で整礎であることとする。つまり $`s_0 \to s_1 \to s_2 \to \cdots`$ という無限列が無いことである。

**定理（ラベルの上界による停止）.** 状態 $`s \in X`$ とラベル $`\alpha \in L`$ の間の関係 $`\mathrm{valid}(s, \alpha)`$ が次を満たすとする。

- ある $`\alpha_0`$ があって、どの状態 $`s`$ でも $`\mathrm{valid}(s, \alpha_0)`$ である。
- $`\mathrm{valid}(s, \alpha)`$ で $`s \to t`$ なら、ある $`\alpha' \lt \alpha`$ で $`\mathrm{valid}(t, \alpha')`$ である。

このとき、$`\to`$ は整礎である。つまり $`s_0 \to s_1 \to s_2 \to \cdots`$ という無限列は無い。

**証明.** $`\alpha`$ についての整礎帰納法で、「$`\mathrm{valid}(s, \alpha)`$ なら $`s`$ は到達可能」を示す。ここで到達可能は、逆向きの関係についての §1 の意味である。$`s \to t`$ なら、$`t`$ に $`\alpha' \lt \alpha`$ で $`\mathrm{valid}(t, \alpha')`$ となるものがある。帰納法の仮定から $`t`$ は到達可能である。よって $`s`$ も到達可能である。1 つめの条件から、すべての状態は到達可能である。§1 の性質から、$`\to`$ は整礎である。$`\square`$

大事な点は、ラベルが 1 つの状態に 1 つに決まっている必要が無いことである。「どれか 1 つのラベルで $`\mathrm{valid}`$ が成り立つ」ことと「1 歩進むと、もっと小さいラベルで成り立つ」ことだけを使う。

公式の ω-Y の展開への当てはめは [06](06-combinatorial-layer.md) §8 で書く。
