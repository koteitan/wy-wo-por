# 公式の ω-Y 数列と山

前提

| ノート | ここで使う言葉 |

| [01 順序数と ω₁](01-ordinals.md) | 順序数、$`\omega^\omega`$ より小さい順序数の Cantor の標準形、$`k`$ 次の係数 $`c_k(\alpha)`$、次数 $`\deg \alpha`$、和 $`\alpha + \omega^e`$ |
| [02 整礎関係と整礎再帰](02-well-founded.md) | 整礎、有限列の辞書式順序 |

このノートは、公式の ω-Y 数列の式、山、展開の規則を定義する。規則は [notes/03-official-rule.md](../notes/03-official-rule.md) の書き起こしを、このノートの記号で書き直したものである。

例の値は、この規則を Python で書いたプログラムで計算した。このプログラムは、このリポジトリの実装 [reference/official/omegay.cjs](../reference/official/omegay.cjs) と 3897 通りの展開で同じ結果を出す。対象は、長さ 5 以下・値 6 以下の式と、このノートに出る式の展開 $`s[n]`$（$`n = 1, 2, 3`$、§5）である。

## 1. 式

**定義（式）.** **式** は正の整数の有限列 $`s = (s_0, \ldots, s_{x_0})`$ で、空か、$`s_0 = 1`$ のものである。

- 項 $`s_c`$ の番号 $`c`$ を **列** と呼ぶ。列は 0 から数える。
- 最後の列を $`x_0`$ と書く。
- 式の順序は [02](02-well-founded.md) §1 の有限列の辞書式順序である。この順序は式の全体の上では整礎でない（[02](02-well-founded.md) §1 の例 $`(1,2) \gt (1,1,2) \gt (1,1,1,2) \gt \cdots`$）。

**出典.** ω-Y 数列は Yukito 氏が 2021 年に発表した。Yukito 氏は 2021-09-01 に完成を宣言し、定義を Naruyoko 氏のプログラム [Study and Expand Sequence(仮)](https://naruyoko.github.io/StudyAndExpandSequence/) とした。文章の定義は無い。このノートの規則は、そのプログラムの出力と比べて書き起こしたものである（[notes/00-survey.md](../notes/00-survey.md) §1.1、§1.2、[notes/03-official-rule.md](../notes/03-official-rule.md) §6）。

## 2. 行

山の **行** は、$`\omega^\omega`$ より小さい順序数である。一番下の行は 0 である。行は $`\alpha, \beta`$ と書く。係数 $`c_k(\alpha)`$、次数 $`\deg \alpha`$、和 $`\alpha + \omega^e`$ は [01](01-ordinals.md) §1 のとおりである。

**定義（跳び）.** 2 つの行 $`\alpha, \beta`$ の **跳び** を次で定める。

```math
\mathrm{jump}(\alpha, \beta) = \begin{cases} 0 & (\alpha = \beta) \cr 1 + \max\{\, k \mid c_k(\alpha) \ne c_k(\beta) \,\} & (\alpha \ne \beta) \end{cases}
```

定義から $`\mathrm{jump}(\alpha, \beta) = \mathrm{jump}(\beta, \alpha)`$ である。

**定義（次の行）.** $`B(\alpha, \beta) = \alpha + \omega^{\mathrm{jump}(\alpha, \beta)}`$ とする。

**例（Python で計算した）.**

| $`\alpha`$ | $`\beta`$ | $`\mathrm{jump}(\alpha, \beta)`$ | $`B(\alpha, \beta)`$ |
|---|---|---|---|
| $`0`$ | $`0`$ | 0 | $`1`$ |
| $`1`$ | $`1`$ | 0 | $`2`$ |
| $`1`$ | $`0`$ | 1 | $`1 + \omega = \omega`$ |
| $`\omega`$ | $`0`$ | 2 | $`\omega + \omega^2 = \omega^2`$ |
| $`\omega`$ | $`\omega`$ | 0 | $`\omega + 1`$ |
| $`\omega + 1`$ | $`\omega`$ | 1 | $`\omega \cdot 2`$ |

- $`\alpha = \beta`$ なら、行は 1 だけ上がる。これは 1-Y 数列（[koteitan/1y-wo-por](https://github.com/koteitan/1y-wo-por) が扱う数列）の山の行と同じ動きである。
- $`\alpha \ne \beta`$ なら、行は $`\omega`$ の冪だけ上がる。和 $`\alpha + \omega^e`$ では、$`e`$ 次より下の係数が消える（[01](01-ordinals.md) §1）。

## 3. 山

**定義（山）.** 式 $`s`$ の **山** $`M(s)`$ は節点の集まりである。**節点** は（列、行）の組で決まり、正の整数の **値** を持つ。節点 $`u`$ の列を $`\mathrm{col}(u)`$、行を $`\mathrm{row}(u)`$、値を $`v(u)`$ と書く。列 $`c = 0, 1, \ldots, x_0`$ の順に、左から作る。

1. 列 $`c`$ の **最下の節点** を、行 0、値 $`s_c`$ で置く。
2. 列 $`c`$ の一番上の節点 $`u`$ の値が 1 より大きい間、次をくり返す。下の「親の探し方」で節点 $`p`$ を見つける。$`u`$ の上に新しい節点を置く。その行は $`B(\mathrm{row}(u), \mathrm{row}(p))`$、値は $`v(u) - v(p)`$ である。$`p`$ を新しい節点の **親** と呼ぶ。
3. 値が 1 の節点を置いたら、列 $`c`$ は終わる。

**定義（親の探し方）.** $`u`$ を列 $`c`$ の一番上の節点とし、その値を $`v`$ とする。候補 $`q`$ を $`u`$ から始め、次をくり返す。

1. 上限を $`\mathrm{row}(q)`$ とする。
2. 左へ移る。$`q`$ が最下の節点なら、列 $`\mathrm{col}(q) - 1`$ の最下の節点へ移る。そうでなければ、$`q`$ の親へ移る。
3. 移った先の列で、すぐ上の節点の行が上限以下である限り、上へ登る。着いた節点を新しい候補 $`q`$ とする。
4. $`v(q) \lt v`$ なら止める。この $`q`$ が親である。

式では、親はいつも見つかる。候補の列は 1 回ごとに左へ進む。列 0 の節点は値 1 の最下の節点だけで、$`1 \lt v`$ だからである。

**定義（親、$`u^+`$、辺）.** 最下の節点でない節点 $`u`$ について、$`u`$ を置いたときに見つけた親を $`\pi(u)`$ と書く。$`\pi(u)`$ の列は $`u`$ の列より左にある。節点 $`u`$ のすぐ上の節点を $`u^+`$ と書く。組 $`(u, u^+)`$ を **辺** と呼ぶ。$`\mathrm{jump}(\mathrm{row}(u), \mathrm{row}(\pi(u^+)))`$ を **辺の跳び** と呼ぶ。作り方から、辺 $`(u, u^+)`$ について次が成り立つ。

```math
\mathrm{row}(u^+) = B\bigl(\mathrm{row}(u),\ \mathrm{row}(\pi(u^+))\bigr), \qquad v(u) = v(u^+) + v(\pi(u^+))
```

どの列でも、一番上の節点の値は 1 である。

**定義（行の中の親）.** 節点 $`u`$ に $`u^+`$ があり、$`\mathrm{row}(\pi(u^+)) = \mathrm{row}(u)`$ のとき、$`P(u) = \pi(u^+)`$ と書き、$`u`$ の **行の中の親** と呼ぶ。このとき辺の跳びは 0 で、$`\mathrm{row}(u^+) = \mathrm{row}(u) + 1`$ である。それ以外のとき、$`P(u)`$ は無い。$`P(u)`$ は $`u`$ と同じ行にあり、$`u`$ より左の列にある。1 つの行の中で $`P`$ をたどる形は、1-Y の山の親に当たる。

**定義（次数の上界）.** 山のどの節点の行の次数も $`D`$ 以下のとき、$`D`$ を山の **次数の上界** と呼ぶ。

**表の書き方.** 列の節点を下から順に `行:値←c列@親の行` と並べる。例えば `1:16←c1@0` は、行 1 の節点で、値が 16 で、親が列 1 の行 0 の節点であることを表す。最下の節点には親が無いので、`0:20` のように書く。

**例 1（$`M(1,4,20)`$、Python で計算した）.**

- 列 0：`0:1`
- 列 1：`0:4, 1:3←c0@0, ω:2←c0@0, ω²:1←c0@0`
- 列 2：`0:20, 1:16←c1@0, 2:13←c1@1, ω:10←c1@1, ω+1:8←c1@ω, ω·2:6←c1@ω, ω²:4←c1@ω, ω²+1:3←c1@ω², ω²+ω:2←c1@ω², ω²·2:1←c1@ω²`

列 1 では、どの節点の親も $`(0, 0)`$（列 0、行 0）である。行は $`B(0,0) = 1`$、$`B(1, 0) = \omega`$（跳び 1）、$`B(\omega, 0) = \omega^2`$（跳び 2）と進む。

列 2 の親の探し方を、下の節点から順に書く。どの節点でも、最初の候補がそのまま親になった。

| 節点（行、値） | 探し方 | 親（値） | 跳び | 次の行 | 次の値 |
|---|---|---|---|---|---|
| $`0`$、20 | 最下の節点なので、列 1 の最下の節点へ移る | $`(1, 0)`$（4） | 0 | $`1`$ | 16 |
| $`1`$、16 | 親 $`(1, 0)`$ へ移り、行 $`1 \le 1`$ なので $`(1, 1)`$ へ登る | $`(1, 1)`$（3） | 0 | $`2`$ | 13 |
| $`2`$、13 | 親 $`(1, 1)`$ へ移る。上の行 $`\omega`$ は 2 より大きいので登らない | $`(1, 1)`$（3） | 1 | $`\omega`$ | 10 |
| $`\omega`$、10 | 親 $`(1, 1)`$ へ移り、行 $`\omega \le \omega`$ なので $`(1, \omega)`$ へ登る | $`(1, \omega)`$（2） | 0 | $`\omega + 1`$ | 8 |
| $`\omega + 1`$、8 | 親 $`(1, \omega)`$ へ移る。登らない | $`(1, \omega)`$（2） | 1 | $`\omega \cdot 2`$ | 6 |
| $`\omega \cdot 2`$、6 | 同じ | $`(1, \omega)`$（2） | 2 | $`\omega^2`$ | 4 |
| $`\omega^2`$、4 | 親 $`(1, \omega)`$ へ移り、$`(1, \omega^2)`$ へ登る | $`(1, \omega^2)`$（1） | 0 | $`\omega^2 + 1`$ | 3 |
| $`\omega^2 + 1`$、3 | 親 $`(1, \omega^2)`$ へ移る | $`(1, \omega^2)`$（1） | 1 | $`\omega^2 + \omega`$ | 2 |
| $`\omega^2 + \omega`$、2 | 同じ | $`(1, \omega^2)`$（1） | 2 | $`\omega^2 \cdot 2`$ | 1 |

新しい行が、列 1 の次の節点の行（$`\omega`$、$`\omega^2`$）に着くと、候補はその節点へ登り、親が変わる。行の中の親は、例えば $`P((2, 0)) = (1, 0)`$、$`P((2, 1)) = (1, 1)`$ である。

**例 2（$`M(1,3,3)`$、Python で計算した）.**

- 列 0：`0:1`
- 列 1：`0:3, 1:2←c0@0, ω:1←c0@0`
- 列 2：`0:3, 1:2←c0@0, ω:1←c0@0`

列 2 の最下の節点（値 3）では、最初の候補 $`(1, 0)`$ の値は 3 で、3 より小さくない。次の候補は列 0 の最下の節点で、値 1 なので親になる。$`P((2, 0)) = (0, 0)`$ である。

## 4. 帯

**定義（帯）.** $`d \ge 1`$ と行 $`\beta`$ について、次の行の集まりを「$`\beta`$ を含む水準 $`d`$ の **帯**」と呼ぶ。

```math
\{\, \alpha \mid c_k(\alpha) = c_k(\beta)\ \ (k \ge d - 1) \,\}
```

帯は $`S, T`$ と書く（記号 $`B`$ は §2 の次の行に使ったので、帯には使わない）。

- 水準 1 の帯は、1 つの行だけの集まり $`\{\beta\}`$ である。
- 水準 2 の帯は、$`c_0`$ だけが違う行の集まりである。1-Y の山 1 つ分の行に当たる。
- 水準 $`d \ge 2`$ の帯 $`S`$ の行 $`\alpha`$ について、$`h_S(\alpha) = c_{d-2}(\alpha)`$ とする。
- $`S[j]`$ は、$`S`$ の中で $`d - 2`$ 次の係数が $`j`$ の行の集まりである。$`S[j]`$ は水準 $`d - 1`$ の帯である。$`j \lt j'`$ なら、$`S[j]`$ の行はどれも $`S[j']`$ の行より小さい。
- $`\mathrm{top}_S(c)`$ は、列 $`c`$ の節点で、行が $`S`$ に入る最も高いものである。無いこともある。

**例.** 0 を含む水準 2 の帯は $`\{\alpha \mid \alpha \lt \omega\}`$ で、$`S[j] = \{j\}`$、$`h_S(\alpha) = \alpha`$ である。0 を含む水準 3 の帯は $`\{\alpha \mid \alpha \lt \omega^2\}`$ で、$`S[j] = \{\alpha \mid \omega \cdot j \le \alpha \lt \omega \cdot (j+1)\}`$、$`h_S(\alpha) = c_1(\alpha)`$ である。$`M(1,4,20)`$ の列 2 では、0 を含む水準 3 の帯での $`\mathrm{top}`$ は行 $`\omega \cdot 2`$ の節点で、$`h_S = 2`$ である。0 を含む水準 2 の帯での $`\mathrm{top}`$ は行 2 の節点で、$`h_S = 2`$ である。

## 5. 展開の規則

式 $`s`$ が空でないとき、自然数 $`n`$（コピーの回数）について展開 $`s[n]`$ を定める。

### 5.1 根とブロック

- $`t`$ を列 $`x_0`$ の一番上の節点とし、$`\tau = \mathrm{row}(t)`$ とする。
- $`s_{x_0} = 1`$ のとき（$`t`$ は最下の節点で、親が無い）と、$`n = 0`$ のときは、$`s[n] = (s_0, \ldots, s_{x_0 - 1})`$ とする。末項を消すだけである。以下、$`s_{x_0} \gt 1`$ かつ $`n \ge 1`$ とする。
- **根** $`r = \pi(t)`$、**根の列** $`c_r = \mathrm{col}(r)`$、**幅** $`w = x_0 - c_r`$ とする。

**列の写像** $`\mu_i`$ を次で定める。

```math
\mu_i(c) = \begin{cases} c & (c \lt c_r) \cr c + i \cdot w & (c \ge c_r) \end{cases}
```

出力の列 $`0, \ldots, x_0 - 1`$ は、$`M(s)`$ の列そのものである。

次に、出力の列 $`X = x + i \cdot w`$ を、$`i = 0, 1, \ldots, n`$ の順に、同じ $`i`$ の中では $`x`$ の小さい順に作る。$`x`$ の範囲は次のとおりである。

```math
x \in \begin{cases} \{x_0\} & (i = 0) \cr \{c_r + 1, \ldots, x_0\} & (1 \le i \lt n) \cr \{c_r + 1, \ldots, x_0 - 1\} & (i = n) \end{cases}
```

- 番号 $`i`$ で作る列をまとめて **ブロック** $`i`$ と呼ぶ。ブロック 0 は列 $`x_0`$ だけである。$`i`$ を **ブロックの番号** と呼ぶ。
- 列 $`X`$ を作るとき、読む節点はいつも元の山 $`M(s)`$ のものである。例外は §5.4 の $`u_q`$ で、これは出力の列から読む。
- $`s[n]`$ は、出力の各列の最下の節点の値を並べたものである。長さは $`x_0 + n \cdot w`$ である。

### 5.2 列の組み立て

列 $`X = x + i \cdot w`$ は、組 $`(\alpha', \ell)`$ の並びから作る。$`\alpha'`$ は行、$`\ell`$ は $`M(s)`$ の列か「無し」である。組は下の部分（§5.3、§5.4）、上の部分（§5.5）の順に出る。行 $`\alpha'`$ は狭義に増える。

- 組 $`(\alpha', \ell)`$ は、列 $`X`$ の行 $`\alpha'`$ に節点 $`u`$ を置く。
- $`\ell`$ が無ければ、$`u`$ に親は無い。
- $`\ell`$ があれば、$`u`$ の親は、出力の列 $`\mu_i(\ell)`$ の節点で、行が $`\alpha'`$ より小さい最も高いものである。そのような節点が無ければ、親は無い。$`\mu_i(\ell) \lt X`$ なので、この列はもう出来ている。
- 値は上から決める。一番上の節点の値は 1 で、ほかは $`v(u) = v(u^+) + v(\pi(u^+))`$ である。

### 5.3 下の部分と項目

$`\tau`$ より下の行を、帯に分ける。$`k \ge 0`$ と $`j \lt c_k(\tau)`$ について、次の集まりは水準 $`k + 1`$ の帯である。

```math
L_{k,j} = \{\, \alpha \mid c_m(\alpha) = c_m(\tau)\ \ (m \gt k),\ \ c_k(\alpha) = j \,\}
```

これらの帯は $`\{\alpha \mid \alpha \lt \tau\}`$ を分ける。$`k`$ の大きい順、同じ $`k`$ では $`j`$ の小さい順に並べると、行の順になる。例えば $`\tau = \omega`$ なら $`L_{1,0} = \{\alpha \mid \alpha \lt \omega\}`$ だけである。$`\tau = \omega + 2`$ なら $`L_{1,0}`$、$`L_{0,0} = \{\omega\}`$、$`L_{0,1} = \{\omega + 1\}`$ である。

**定義（項目）.** **項目** は 5 つ組 $`(S, T, C, o, \varepsilon)`$ である。

- $`S`$ は源の帯（$`M(s)`$ の行の帯）、$`T`$ は行き先の帯である。$`S`$ と $`T`$ の水準は同じである。
- $`C`$ は、根の列の節点の行を写すときの、その行である。写さないときは $`C = \bot`$ と書く。
- $`o`$ は自然数（ずれ）である。
- $`\varepsilon \in \{0, 1\}`$ は、帯の下の方を写さないかどうかを表す。

最初の項目の並びは、$`(L_{k,j}, L_{k,j}, \bot, 0, 0)`$ を行の順に並べたものである。項目を先頭から順に処理する。水準 1 の項目は、組を 1 つ出すか、何も出さない。水準 2 以上の項目は、その場で子の項目の並び（$`j`$ の小さい順）に置きかわる。つまり、深さ優先で処理する。

**水準 1 の項目.** $`S = \{\alpha\}`$、$`T = \{\alpha'\}`$ とする。

- 列 $`x`$ に行 $`\alpha`$ の節点が無ければ、何も出さない。
- $`C = \bot`$ なら、組 $`(\alpha', \ell)`$ を出す。$`\ell`$ は節点 $`(x, \alpha)`$ の親の列である。$`\alpha = 0`$ なら $`\ell`$ は無い。
- $`C \ne \bot`$ なら、組 $`(\alpha', \ell)`$ を出す。$`\ell`$ は節点 $`(x, C)`$ の親の列である。$`C = 0`$ なら $`\ell = x - 1`$ とする。

$`C \ne \bot`$ の項目から出る組は、行 $`\alpha`$ の節点の親の列の代わりに、行 $`C`$ の節点の親の列を使う。行 $`C`$ は根の列の節点の行である。このうち $`\varepsilon = 0`$ の項目から出るものを **根の行の写し**、$`\varepsilon = 1`$ の項目から出るものを **すき間の写し** と呼ぶ。

### 5.4 水準 2 以上の項目

$`S`$ の水準を $`d \ge 2`$ とする。$`M(s)`$ で次の節点を取る。

- $`u_x = \mathrm{top}_S(x)`$。無ければ、何も出さない（子の項目は無い）。
- $`u_0 = \mathrm{top}_S(x_0)`$、$`u_r = \mathrm{top}_S(c_r)`$。
- $`h_x, h_0, h_r`$ は、$`u_x, u_0, u_r`$ の行の $`h_S`$ である。節点が無ければ 0 とする。

**定義（上がる）.** 次の 3 つがすべて成り立つとき、「列 $`x`$ は帯 $`S`$ で **上がる**」という。

1. $`u_r`$ がある。
2. **参照の行** $`Z`$ を、$`c_0(\mathrm{row}(u_r)) \gt 0`$ なら $`\mathrm{row}(u_r) - 1`$（$`c_0`$ を 1 減らした行）、そうでなければ $`\mathrm{row}(u_r)`$ とする。節点 $`(x, Z)`$ がある。
3. $`(x, Z), P(x, Z), P^2(x, Z), \ldots`$ と行の中の親をたどる。列が $`c_r`$ 以下になる最初の節点があり、その列はちょうど $`c_r`$ である。

これは 1-Y の上がる列の判定を、帯ごとに行うものである。

**記号.**

- **持ち上げ** $`\Delta = (h_0 - h_r) \cdot i`$。
- $`\delta = 1`$（$`d = 2`$ のとき）、$`\delta = 0`$（$`d \ge 3`$ のとき）。
- $`u_q = \mathrm{top}_T(c_r + i \cdot w)`$ を、**出力** の列 $`c_r + i \cdot w`$ から取る。$`i = 0`$ ではこれは列 $`c_r`$ で、$`i \ge 1`$ では 1 つ前のブロックの最後の列である。$`h_q`$ は $`u_q`$ の行の $`h_T`$（無ければ 0）である。
- **世代の数** $`g`$（場合 4 だけで使う）：$`C \ne 0`$ なら、列 $`x`$ から始めて「列 $`c`$ から、節点 $`(c, C)`$ の親の列へ移る」ことを、列が $`c_r`$ 以下になるまでくり返した回数である。$`C = 0`$ なら $`g = x - c_r`$ とする。

子の項目を、次の 4 つの場合に分けて作る。$`[\,\cdot\,]`$ は、成り立てば 1、成り立たなければ 0 である。

**場合 1：列 $`x`$ が帯 $`S`$ で上がらないとき.** そのまま写す。$`j = 0, \ldots, h_x`$ について $`(S[j], T[j], \bot, 0, 0)`$。

**場合 2：上がり、$`C = \bot`$、$`\varepsilon = 0`$ のとき.** $`j = 0, \ldots, h_x + \Delta`$ について、次の子を作る。

| 範囲 | 子の項目 |
|---|---|
| $`j \lt h_r`$ | $`(S[j], T[j], \bot, 0, 0)`$ |
| $`h_r \le j \lt h_r + \Delta + \delta`$ | $`(S[h_r], T[j], \mathrm{row}(u_r), 0, [j \gt h_r])`$ |
| $`j \ge h_r + \Delta + \delta`$ | $`(S[j - \Delta], T[j], \bot, 0, [i \ne 0 \wedge j = h_r + \Delta])`$ |

$`S[j]`$（$`j \lt h_r`$）はそのまま写す。$`S[j]`$（$`j \ge h_r + \delta`$）は $`T[j + \Delta]`$ へ持ち上げる。その間の $`T[j]`$（$`h_r \le j \lt h_r + \Delta + \delta`$）には、根の行 $`\mathrm{row}(u_r)`$ を写す。

**場合 3：上がり、$`C = \bot`$、$`\varepsilon = 1`$ のとき.** $`H = h_q + h_x`$（$`i = 0`$ なら $`H = h_x`$）とする。$`j = h_r, \ldots, H`$ について、次の子を作る。

| 範囲 | 子の項目 |
|---|---|
| $`j \lt h_r + h_q + \delta`$ | $`(S[h_r], T[j - h_r], \mathrm{row}(u_r), 0, 1)`$ |
| それ以外 | $`(S[j - h_q], T[j - h_r], \bot, 0, [j = h_r + h_q])`$ |

**場合 4：上がり、$`C \ne \bot`$ のとき.** 根の行を写している途中である。$`H = h_q + g - o`$（$`i = 0`$ なら $`H = h_x`$）とする。$`j = 0, \ldots, H`$ について $`o_j = \max(j - h_q + o,\ 0)`$ とし、次の子を作る。

| 条件 | 子の項目 |
|---|---|
| $`\varepsilon = 1`$ | $`(S[h_r], T[j], C, o_j, 1)`$ |
| $`\varepsilon = 0`$、$`j \lt h_r`$ | $`(S[j], T[j], \bot, 0, 0)`$ |
| $`\varepsilon = 0`$、$`j \ge h_r`$ | $`(S[h_r], T[j], C, o_j, [j \gt h_r])`$ |

### 5.5 上の部分

$`x' = x`$（$`x \lt x_0`$ のとき）、$`x' = c_r`$（$`x = x_0`$ のとき）とする。$`M(s)`$ の列 $`x'`$ の節点 $`u`$ で、行が $`\tau`$ 以上のものについて、下から順に組 $`(\mathrm{row}(u), \ell)`$ を出す。$`\ell`$ は $`\pi(u)`$ の列である。$`\tau`$ 以上の行は持ち上げない。

### 5.6 起こらない場合

次の場合には、規則が意味を持たない。このノートでは、これらの場合は展開が失敗したとする。

- 上がらないのに $`C \ne \bot`$、$`o \ne 0`$ または $`\varepsilon = 1`$ である。
- 場合 4 で $`\varepsilon = 0`$ なのに、$`u_q`$ が無いか $`o \ne 0`$ である。
- 場合 4 と水準 1 の項目で、節点 $`(x, C)`$ が無い。世代の数を数える途中で、行 $`C`$ の節点が無い。
- 1 つの列の中で、行が狭義に増えない。

公式のプログラムとの比較の試験では、どれも起こらなかった（[notes/03-official-rule.md](../notes/03-official-rule.md) §6）。

## 6. 例

### 6.1 $`(1,3,3)[2]`$

$`M(1,3,3)`$ は §3 の例 2 である。$`t = (2, \omega)`$、$`\tau = \omega`$、$`r = (0, 0)`$、$`c_r = 0`$、$`w = 2`$ である。出力の列 0、1 は $`M(s)`$ のままである。ブロック 0 は列 2（$`x = 2`$）、ブロック 1 は列 3（$`x = 1`$）と列 4（$`x = 2`$）、ブロック 2 は列 5（$`x = 1`$）である。$`\tau = \omega`$ なので、下の部分の帯は $`L_{1,0} = \{\alpha \mid \alpha \lt \omega\}`$（水準 2）だけである。

**列 4（$`i = 1`$、$`x = 2`$）を 1 歩ずつたどる.**

1. 項目 $`(L_{1,0}, L_{1,0}, \bot, 0, 0)`$（水準 2）。$`S[j] = \{j\}`$ である。$`u_x = u_0 = (2, 1)`$、$`u_r = (0, 0)`$ で、$`h_x = h_0 = 1`$、$`h_r = 0`$ である。$`\Delta = (1 - 0) \cdot 1 = 1`$、$`\delta = 1`$ である。
2. 上がるか：$`c_0(\mathrm{row}(u_r)) = 0`$ なので $`Z = 0`$ である。$`P((2, 0)) = (0, 0)`$ で、その列 0 はちょうど $`c_r`$ である。列 2 は上がる。
3. 場合 2 で、$`j = 0, 1, 2`$ の子を作る。$`j = 0, 1`$ は $`h_r \le j \lt 2`$ なので $`(S[0], T[0], 0, 0, 0)`$ と $`(S[0], T[1], 0, 0, 1)`$ である。$`j = 2`$ は $`(S[1], T[2], \bot, 0, 0)`$ である。
4. $`(S[0], T[0], 0, 0, 0)`$：$`C = 0`$ なので $`\ell = x - 1 = 1`$ で、組 $`(0, 1)`$ を出す。行 0 なので親は無い。根の行の写しである。
5. $`(S[0], T[1], 0, 0, 1)`$：組 $`(1, 1)`$ を出す。$`\mu_1(1) = 3`$ なので、親は出力の列 3 の行 0 の節点である。すき間の写しである。
6. $`(S[1], T[2], \bot, 0, 0)`$：節点 $`(2, 1)`$ の親の列は 0 で、組 $`(2, 0)`$ を出す。$`\mu_1(0) = 2`$ なので、親は出力の列 2 で行 2 より下の最も高い節点、つまり行 1 の節点である。
7. 上の部分：$`x = x_0`$ なので、列 $`c_r = 0`$ を見る。列 0 に $`\omega`$ 以上の行の節点は無い。
8. 結果は `0, 1←c3@0, 2←c2@1` である。値は上から 1、$`1 + 1 = 2`$、$`2 + 5 = 7`$ である（出力の列 2 の行 1 の値は 1、列 3 の行 0 の値は 5）。

**出力の列 2〜5（Python で計算した）.**

- 列 2：`0:2, 1:1←c0@0`
- 列 3：`0:5, 1:3←c2@0, 2:2←c2@1, ω:1←c2@1`
- 列 4：`0:7, 1:2←c3@0, 2:1←c2@1`
- 列 5：`0:12, 1:5←c4@0, 2:3←c4@1, 3:2←c4@2, ω:1←c4@2`

よって $`s[2] = (1, 3, 2, 5, 7, 12)`$ である。

### 6.2 $`(1,4,4)[2]`$ の列 4（場合 4 の例）

$`M(1,4,4)`$ の列 1 と列 2 は、どちらも `0:4, 1:3←c0@0, ω:2←c0@0, ω²:1←c0@0` である（Python で計算した）。$`t = (2, \omega^2)`$、$`\tau = \omega^2`$、$`c_r = 0`$、$`w = 2`$ で、下の部分の帯は $`L_{2,0} = \{\alpha \mid \alpha \lt \omega^2\}`$（水準 3）だけである。列 4 は $`i = 1`$、$`x = 2`$ である。

1. 水準 3 の項目：$`h_S = c_1`$ である。$`u_x = u_0 = (2, \omega)`$、$`u_r = (0, 0)`$ で、$`h_x = h_0 = 1`$、$`h_r = 0`$、$`\Delta = 1`$、$`\delta = 0`$ である。列 2 は上がる（$`Z = 0`$、$`P((2,0)) = (0,0)`$）。場合 2 で、子は $`(S[0], T[0], 0, 0, 0)`$、$`(S[0], T[1], \bot, 0, 1)`$、$`(S[1], T[2], \bot, 0, 0)`$ である。
2. 1 つ目の子（水準 2、場合 4）：$`C = 0`$ なので $`g = x - c_r = 2`$ である。$`u_q`$ は出力の列 2（`0:3, 1:2←c0@0, ω:1←c0@0`）の、$`\omega`$ より下の一番上の節点で、$`h_q = 1`$ である。$`H = 1 + 2 - 0 = 3`$ で、行 0〜3 に根の行を写す。親の列は $`\mu_1(x - 1) = 3`$ である。
3. 2 つ目の子（水準 2、場合 3）：$`T = \{\alpha \mid \omega \le \alpha \lt \omega \cdot 2\}`$ である。出力の列 2 のこの帯の一番上は行 $`\omega`$ で、$`h_q = 0`$ である。$`H = 0 + 1 = 1`$ である。行 $`\omega`$ にすき間の写し（親の列 3）、行 $`\omega + 1`$ に節点 $`(2, 1)`$ の写し（親の列 $`\mu_1(0) = 2`$）を置く。
4. 3 つ目の子（水準 2）：源の帯 $`\{\alpha \mid \omega \le \alpha \lt \omega \cdot 2\}`$ に列 $`c_r = 0`$ の節点が無いので、上がらない（場合 1）。行 $`\omega \cdot 2`$ に節点 $`(2, \omega)`$ の写し（親の列 2）を置く。
5. 結果（Python で計算した）は `0:34, 1:23←c3@0, 2:15←c3@1, 3:9←c3@2, ω:3←c3@2, ω+1:2←c2@ω, ω·2:1←c2@ω` である。

すき間の写しは行 1、2、3 の 3 つである。この大きさ 3 は、世代の数 $`g = 2`$ と $`h_q = 1`$ の和である。

## 7. weak-magma ω-Y との違い

Phyrion 氏が停止性を証明した weak-magma ω-Y は、展開の規則が公式と違う別の数列である。その規則は [koteitan/wmwy-wo-por の study/](https://github.com/koteitan/wmwy-wo-por/tree/main/study) の 05 にある。違うのは次の 3 か所である（[notes/03-official-rule.md](../notes/03-official-rule.md) §4）。

| 部分 | weak-magma ω-Y | 公式（§5） |
|---|---|---|
| 持ち上げる節点の選び方 | 根の列の節点と、行の中の親の鎖でつながる節点を選び、その上の節点を持ち上げる | 帯ごとに、列が上がるかを参照の行 $`Z`$ で決める。上がる列は、$`S[j]`$（$`j \ge h_r`$）をまとめて持ち上げる |
| 持ち上げる量 | 1 つ前のブロックの最後の列の行から数える | 帯の中の係数の差 $`\Delta = (h_0 - h_r) \cdot i`$ |
| すき間の埋め方 | すき間の節点の親を、どれも 1 本の列から取る | 根の行の写し。親の列は、行 $`C`$ の節点の親の列を写した列である（$`C = 0`$ では 1 つ左の列を写した列） |

値の例を [notes/00-survey.md](../notes/00-survey.md) §1.6 から引く。weak-magma ω-Y では $`(1,3,3)[2] = (1,3,2,5,4,9)`$、$`(1,4,4)[2] = (1,4,3,11,10,38)`$ である。公式では §6.3 のとおり $`(1,3,2,5,7,12)`$ と $`(1,4,3,11,34,101)`$ である。このノートでは weak-magma ω-Y の値を計算していない。

公式では、列 $`(1,3,2,5,4,9,8,17,\ldots)`$ の上限は $`(1,3,2,5,5)`$ である。実際、$`(1,3,2,5,5)[n]`$ は次のとおりである（Python で計算した）。

```math
(1,3,2,5,5)[1] = (1,3,2,5,4,9), \quad (1,3,2,5,5)[2] = (1,3,2,5,4,9,8,17), \quad (1,3,2,5,5)[3] = (1,3,2,5,4,9,8,17,16,33)
```

これは [Googology Wiki (Miraheze) の記事](https://googology.miraheze.org/wiki/%5C(%5Comega%5C)-Y_sequence) の記述と同じである。公式の $`(1,3,3)`$ はこれより大きく、$`(1,3,3)[n]`$ は $`(1,3,2,5,7,12,\ldots)`$ である。weak-magma ω-Y では $`(1,3,3)[n]`$ が $`(1,3,2,5,4,9,\ldots)`$ になる。

## 8. 1 歩の展開と最終定理

**定義（1 歩の展開）.** 有限列 $`s, t`$ について、$`t \prec s`$ とは、$`s`$ が空でなく、ある $`n`$ で $`s[n]`$ が定まり $`t = s[n]`$ であることをいう。

式でない列（0 を含む列など）では山が作れないので、展開は失敗する。§5.6 の場合も失敗とする。展開が失敗する列から $`\prec`$ で進む先は無い。

**最終定理.** $`\prec`$ は有限列の全体の上で整礎である。言いかえると、展開を無限に続けることはできない。つまり $`s_0 \succ s_1 \succ s_2 \succ \cdots`$ という無限列は無い。

証明は [06](06-combinatorial-layer.md)〜[10](10-official-descent.md) にある。

試した範囲では、$`s[n]`$ はいつも $`s`$ より辞書式で小さかった。長さ 5 以下・値 5 以下の式（末項が 1 のものを除く）と $`n = 1, 2, 3`$ の 1872 回の展開で確かめた（Python）。しかし辞書式順序は式の全体の上で整礎でない（§1）ので、このことから最終定理は出ない。
