## 1. 列の上の型板

[03](03-sigma1-elementary.md) §7 の型板を、山の列の上で使う。変数は山の列である。長さ $`m`$、列が $`n`$ 個の型板 $`K`$ は、各座標に列の番号（$`\{0, \ldots, n-1\}`$ の元）か $`\top`$ を置いたものである。このノートでは、型板を $`K, K'`$ と書く（$`t`$ は [05](05-omegay-mountain.md) の一番上の節点に使う）。列のラベル $`f : \{0, \ldots, n-1\} \to \mathrm{Label}`$ で評価した鍵 $`\mathrm{eval}\,K\,f`$ は、座標 $`k`$ が $`K_k = j`$ なら $`f(j)`$、$`K_k = \top`$ なら $`\top`$ の鍵である。

**定義（列の番号で評価した鍵）.** 列の番号 $`j`$ をそのままラベル $`j`$ とみなして評価した鍵 $`\mathrm{eval}\,K\,\mathrm{id}`$ を、$`K`$ の **列の番号で評価した鍵** と呼ぶ。型板の比べ方 $`K \le K'`$、$`K \lt K'`$ は、列の番号で評価した鍵の比べ方とする。このノートでは、型板を $`(0, \top)`$ のように列の番号で書く。

**定理 1.** $`f`$ が狭義増加なら、$`K \le K'`$ から $`\mathrm{eval}\,K\,f \le \mathrm{eval}\,K'\,f`$ が、$`K \lt K'`$ から $`\mathrm{eval}\,K\,f \lt \mathrm{eval}\,K'\,f`$ が出る。

**証明.** $`K`$ と $`K'`$ が同じなら明らかである。そうでなければ、最初に違う座標を $`k`$ とする。$`k`$ より前の座標は同じなので、$`f`$ で評価しても同じである。$`K \lt K'`$ なので、座標 $`k`$ は次のどちらかである。$`K_k = j`$ で $`K'_k = \top`$ なら、$`f(j) \lt \top`$ である。$`K_k = j \lt j' = K'_k`$ なら、$`f`$ が狭義増加なので $`f(j) \lt f(j')`$ である。どちらでも $`\mathrm{eval}\,K\,f \lt \mathrm{eval}\,K'\,f`$ である。$`\square`$

これで、型板の比べ方は、ラベルを選ぶ前に、列の番号だけで決まる。

**定義（付け替え）.** 列の写像 $`\sigma : \{0, \ldots, n-1\} \to \{0, \ldots, n'-1\}`$ について、$`K`$ の各座標の列の番号 $`j`$ を $`\sigma(j)`$ に置きかえた型板を $`\sigma(K)`$ と書く。$`\top`$ はそのままである。定義から、新しい列のラベル $`h`$ について次が成り立つ。

```math
\mathrm{eval}\,\sigma(K)\,h = \mathrm{eval}\,K\,(h \circ \sigma)
```

**例.** $`m = 2`$、$`n = 3`$ とする。$`K = (0, \top)`$ なら $`\mathrm{eval}\,K\,f = (f(0), \top)`$、$`K' = (0, 2)`$ なら $`\mathrm{eval}\,K'\,f = (f(0), f(2))`$ である。座標 0 は同じで、座標 1 で $`2 \lt \top`$ なので、$`K' \lt K`$ である。$`\sigma(j) = j + 1`$ なら $`\sigma(K') = (1, 3)`$ である。

## 2. 原子と図式

列を $`\{0, \ldots, n-1\}`$、列のラベルを $`f`$ とする。型板の長さは決まった $`m`$ とする。

**定義（内部の原子）.** **内部の原子** は組 $`(p, q, K)`$ である。$`p \lt q`$ は列、$`K`$ は型板である。$`f`$ で成り立つとは、$`R(\mathrm{eval}\,K\,f,\ f(p),\ f(q))`$ のことである。$`p`$ を原子の親の列、$`q`$ を子の列と呼ぶ。

**定義（上端の原子）.** **上端の原子** は組 $`(p, K)`$ である。$`f`$ と上端 $`b`$ で成り立つとは、$`R(\mathrm{eval}\,K\,f,\ f(p),\ b)`$ のことである。上端の原子は、[04](04-patterns-of-resemblance.md) §4 の要求を原子の形で書いたものである。

$`\mathrm{eval}\,K\,f`$ を原子の鍵と呼ぶ。

**定義（図式）.** **図式** $`(G, N)`$ は、内部の原子の有限の一覧 $`G`$ と、上端の原子の有限の一覧 $`N`$ の組である。図式が $`f`$ と上端 $`b`$ で成り立つとは、$`G`$ の原子がすべて $`f`$ で成り立ち、$`N`$ の原子がすべて $`f`$ と上端 $`b`$ で成り立つことである。

## 3. 尺度の根と、山の辺の鍵

$`M`$ を山、$`D`$ をその次数の上界とする（[05](05-omegay-mountain.md) §3）。

**定義（尺度の根）.** $`k`$ を自然数とする。節点 $`u`$ に $`u^+`$ があり、辺 $`(u, u^+)`$ の跳びが $`k`$ 以下のとき、$`\pi(u^+)`$ を $`u`$ の **尺度 $`k`$ の親** と呼ぶ。それ以外のとき、尺度 $`k`$ の親は無い。$`u`$ から尺度 $`k`$ の親を、無くなるまでたどって着いた節点を、**尺度 $`k`$ の根** $`\rho_k(u)`$ と呼ぶ。たどるたびに列は左へ進むので、いつか止まる。

$`k \lt k'`$ なら、尺度 $`k`$ の親をたどる道は、尺度 $`k'`$ の親をたどる道の最初の部分である。だから $`\rho_{k'}(u)`$ は $`\rho_k(u)`$ と同じ列か、それより左の列にある。

**定義（辺の鍵）.** 辺 $`e = (u, u^+)`$ の親を $`\pi = \pi(u^+)`$、跳びを $`d`$ とする。$`\mathrm{row}(u^+) = \mathrm{row}(u) + \omega^d`$ の次数は $`d`$ 以上なので、$`d \le D`$ である。$`e`$ の **辺の鍵** は、長さ $`D + 1`$ の型板で、座標は尺度 $`D, D-1, \ldots, 0`$ の順に並ぶ。

```math
\kappa_D(e) = \bigl(\mathrm{col}\,\rho_D(\pi),\ \mathrm{col}\,\rho_{D-1}(\pi),\ \ldots,\ \mathrm{col}\,\rho_d(\pi),\ \underbrace{\top, \ldots, \top}_{d}\bigr)
```

尺度 $`k \ge d`$ の座標は $`\mathrm{col}\,\rho_k(\pi)`$、尺度 $`k \lt d`$ の座標は $`\top`$ である。有限の座標はどれも、親の列以下の列を指す。子の列は指さない。

**例（Python で計算した）.** $`f_j`$ は列 $`j`$ のラベルである。辺は（列、下の節点の行 → 上の節点の行）で書く。

| 式 | $`D`$ | 辺 | 親 | 辺の跳び | 鍵 |
|---|---|---|---|---|---|
| $`(1,3)`$ | 1 | 列 1、$`0 \to 1`$ | $`(0, 0)`$ | 0 | $`(f_0, f_0)`$ |
| | | 列 1、$`1 \to \omega`$ | $`(0, 0)`$ | 1 | $`(f_0, \top)`$ |
| $`(1,4)`$ | 2 | 列 1、$`0 \to 1`$ | $`(0, 0)`$ | 0 | $`(f_0, f_0, f_0)`$ |
| | | 列 1、$`1 \to \omega`$ | $`(0, 0)`$ | 1 | $`(f_0, f_0, \top)`$ |
| | | 列 1、$`\omega \to \omega^2`$ | $`(0, 0)`$ | 2 | $`(f_0, \top, \top)`$ |
| $`(1,3,5)`$ | 1 | 列 2、$`0 \to 1`$ | $`(1, 0)`$ | 0 | $`(f_0, f_0)`$ |
| | | 列 2、$`1 \to \omega`$ | $`(0, 0)`$ | 1 | $`(f_0, \top)`$ |

$`(1,3,5)`$ の列 2 の最初の辺は、親が列 1 にあるのに、鍵は列 0 を指す。親 $`(1, 0)`$ から上への辺は跳び 0 で、その親は $`(0, 0)`$ だからである。鍵は親の列ではなく、親の尺度の根の列を指す。

**定理 2（列の中の鍵の増加）.** 同じ列の 2 つの辺では、下の辺の鍵は上の辺の鍵より小さい。定理 1 から、狭義増加のどのラベルで評価しても小さい。

**証明の概略.** 隣り合う 2 つの辺 $`e_1 = (u, u^+)`$、$`e_2 = (u^+, u^{++})`$ を比べれば足りる。親を $`p_1 = \pi(u^+)`$、$`p_2 = \pi(u^{++})`$、跳びを $`d_1, d_2`$ とする。

- $`p_2 = p_1`$ のとき：$`d_2 = d_1 + 1`$ である。$`d_1 = 0`$ なら $`\mathrm{row}(u^+) = \mathrm{row}(p_1) + 1`$ なので跳びは 1 である。$`d_1 \ge 1`$ なら、$`\mathrm{row}(u)`$ と $`\mathrm{row}(p_1)`$ は $`d_1`$ 次以上の係数が等しく、$`\mathrm{row}(u^+)`$ は $`d_1`$ 次の係数だけが 1 大きい。だから $`\mathrm{row}(u^+)`$ と $`\mathrm{row}(p_1)`$ が最初に違うのは $`d_1`$ 次である。2 つの鍵は尺度 $`D, \ldots, d_1 + 1`$ の座標が同じで、尺度 $`d_1`$ の座標が $`\mathrm{col}\,\rho_{d_1}(p_1)`$ から $`\top`$ に変わる。よって $`\kappa_D(e_1) \lt \kappa_D(e_2)`$ である。
- $`p_2 \ne p_1`$ のとき：親の探し方を使う長い場合分けになる。ここでは証明しない。Phyrion 氏の証明にある。

長さ 5 以下・値 5 以下の式（末項が 1 のものを除く）624 個の山の、すべての列で成り立つことを Python で確かめた。

## 4. 原子の系と表現

**定義（原子の系）.** **原子の系** $`E`$ は、山 $`M`$（と次数の上界 $`D`$）ごとに、原子 $`(p, c, K)`$ の有限の一覧 $`E(M)`$ を決めるものである。$`p \lt c`$ は $`M`$ の列、$`K`$ は $`M`$ の列の上の長さ $`D + 1`$ の型板である。原子は内部の原子として読む。

このノートの原子の系は、どれも次の性質を持つ。式 $`s`$ の接頭辞 $`s'`$ の山は $`M(s)`$ の最初の列の部分で、$`E(M(s'))`$ は $`E(M(s))`$ のうち子の列が $`s'`$ の列のものである。原子の列と鍵が、子の列とそれより左の列だけで決まるからである。

**定義（表現）.** 山 $`M`$（最後の列 $`x_0`$）の $`E`$ についての **表現** とは、列のラベル $`f : \{0, \ldots, x_0\} \to \mathrm{Label}`$ で次を満たすものである。

1. $`f`$ は狭義増加である。
2. どの $`f(j)`$ も $`\omega_1`$ より小さい。
3. $`E(M)`$ のどの原子 $`(p, c, K)`$ も $`f`$ で成り立つ。つまり $`R(\mathrm{eval}\,K\,f,\ f(p),\ f(c))`$ である。

Phyrion 氏の証明では、$`E`$ を山の辺の一覧にした。辺 $`e = (u, u^+)`$ の原子は $`(\mathrm{col}\,\pi(u^+),\ \mathrm{col}\,u,\ \kappa_D(e))`$ である。これを **山の辺の系** と呼ぶ。

**例.** $`(1,3,5)`$ の山の辺の系についての表現は、$`f_0 \lt f_1 \lt f_2 \lt \omega_1`$ で次を満たすものである（§3 の例の表から）。

```math
R((f_0, f_0), f_0, f_1), \quad R((f_0, \top), f_0, f_1), \quad R((f_0, f_0), f_1, f_2), \quad R((f_0, \top), f_0, f_2)
```

## 5. 3 つの定理

組合せの層が $`R`$ について使うのは、次の 3 つの定理だけである。$`\theta, \Theta`$ は鍵、$`a, b, \beta`$ はラベルである。$`(G, N)`$ は $`n`$ 個の列の上の図式である。証明は [09](09-obligations.md) にある。

**定理（鍵の弱化）.** $`\theta \le \Theta`$ かつ $`R(\Theta, a, b)`$ なら、$`R(\theta, a, b)`$ である。

**定理（有限反映）.** 次を仮定する。

1. $`f : \{0, \ldots, n-1\} \to \mathrm{Label}`$ は狭義増加で、$`f \lt b`$ である。
2. $`G`$ の原子がすべて $`f`$ で成り立つ。
3. $`N`$ の原子の鍵 $`\mathrm{eval}\,K\,f`$ がどれも $`\theta`$ より小さく、$`N`$ の原子がすべて $`f`$ と上端 $`b`$ で成り立つ。
4. ある列 $`\mathrm{cut}`$ について $`R(\theta, f(\mathrm{cut}), b)`$ である。この列を **切れ目**、この関係を **制御関係** と呼ぶ。

このとき、次の 4 つを満たす $`g : \{0, \ldots, n-1\} \to \mathrm{Label}`$ がある。

1. $`g`$ は狭義増加で、$`g \lt f(\mathrm{cut})`$ である。
2. $`j \lt \mathrm{cut}`$ なら $`g(j) = f(j)`$ である。
3. すべての $`j`$ で $`g(j) \le f(j)`$ である。
4. $`G`$ の原子がすべて $`g`$ で成り立ち、$`N`$ の原子がすべて $`g`$ と上端 $`f(\mathrm{cut})`$ で成り立つ。

原子の鍵が指す列は、切れ目より前でなくてよい。これが [04](04-patterns-of-resemblance.md) §4 の問題 3 に答える点である。

**定理（最初の表現）.** どの図式 $`(G, N)`$ にも、ある $`\beta \lt \omega_1`$ と、狭義増加の $`f \lt \beta`$ があって、図式は $`f`$ と上端 $`\beta`$ で成り立つ。

## 6. 1 回の継ぎ合わせ

有限反映 1 回で、列を増やす。列の数を $`n`$、切れ目を $`\mathrm{cut}`$ とする。

**定義（列の写像）.** 新しい列の数は $`n + (n - \mathrm{cut})`$ である。古い列 $`j \in \{0, \ldots, n-1\}`$ を新しい列へ写す写像を 2 つ使う。

- **そのままの写像**：$`j \mapsto j`$。
- **移す写像**：$`\sigma(j) = j`$（$`j \lt \mathrm{cut}`$）、$`\sigma(j) = n + (j - \mathrm{cut})`$（$`j \ge \mathrm{cut}`$）。
- 列 $`n = \sigma(\mathrm{cut})`$ を **境目の列** と呼ぶ。

**定義（新しいラベル）.** $`f`$ を古いラベル、$`g`$ を有限反映で得たラベルとする。新しいラベル $`h`$ を、列 $`j \lt n`$ には $`g(j)`$、列 $`j \ge n`$ には $`f(\mathrm{cut} + j - n)`$ とする。古い列 $`\mathrm{cut}, \ldots, n-1`$ のラベルが、右端にそのまま並ぶ。有限反映の性質 2 から $`h \circ \sigma = f`$ である。

**例.** $`n = 4`$、$`\mathrm{cut} = 1`$ なら、新しいラベルは次のとおりである。

```math
(g_0, g_1, g_2, g_3, f_1, f_2, f_3), \qquad g_0 = f_0,\quad g_1, g_2, g_3 \lt f_1
```

**定義（分類された原子）.** 新しい列の上の内部の原子 $`(P, Q, K)`$ が、図式 $`(G, N)`$ と切れ目について **分類される** とは、次のどれかであることをいう。

1. $`G`$ の原子そのものである。
2. $`G`$ の原子 $`(p, q, K')`$ があって、$`\sigma(p) = P`$、$`\sigma(q) = Q`$、$`K \le \sigma(K')`$ である。
3. $`N`$ の原子 $`(P, K')`$ があって、$`Q = n`$（境目の列）、$`K \le K'`$ である。

**定理 3（1 回の継ぎ合わせ）.** 有限反映の仮定の下で、そこで得た $`g`$ から作った $`h`$ は狭義増加で、$`h \lt b`$ である。分類された原子は、どれも $`h`$ で成り立つ。

**証明.** $`g`$ は狭義増加で $`g \lt f(\mathrm{cut}) = h(n)`$、右端の $`f(\mathrm{cut}), \ldots, f(n-1)`$ も狭義増加なので、$`h`$ は狭義増加である。$`g \lt f(\mathrm{cut}) \lt b`$ と $`f \lt b`$ から $`h \lt b`$ である。

1. 列 $`j \lt n`$ のラベルは $`g(j)`$ なので、有限反映の性質 4 から成り立つ。
2. $`G`$ の原子は $`f`$ で成り立つ。付け替えの式と $`h \circ \sigma = f`$ から $`\mathrm{eval}\,\sigma(K')\,h = \mathrm{eval}\,K'\,f`$ で、$`h(\sigma(p)) = f(p)`$、$`h(\sigma(q)) = f(q)`$ である。定理 1 から $`\mathrm{eval}\,K\,h \le \mathrm{eval}\,\sigma(K')\,h`$ なので、鍵の弱化で成り立つ。
3. 有限反映の性質 4 から $`R(\mathrm{eval}\,K'\,g,\ g(P),\ f(\mathrm{cut}))`$ である。$`h(P) = g(P)`$、$`h(n) = f(\mathrm{cut})`$、$`\mathrm{eval}\,K'\,h = \mathrm{eval}\,K'\,g`$ である。定理 1 と鍵の弱化で成り立つ。$`\square`$

## 7. 予備を持つ反映のくり返し

展開では、継ぎ合わせを $`n`$ 回くり返す。そのために、次の反映に要る事実を **予備** として持ち運ぶ。

**定義（予備、制御の原子、状態）.** 予備は、内部の原子の一覧 $`F`$ と、上端の原子の一覧 $`T`$ である。**制御の原子** は上端の原子 $`(p_c, K_c)`$ である。$`h`$ を列のラベル、$`\beta`$ をラベル（上端）、$`G`$ を内部の原子の一覧とする。**状態** $`(G, F, T, (p_c, K_c), h, \beta)`$ とは、次の 6 つが成り立つことをいう。

1. $`h`$ は狭義増加である。
2. $`h \lt \beta`$ である。
3. $`G`$ の原子がすべて $`h`$ で成り立つ。
4. $`F`$ の原子がすべて $`h`$ で成り立つ。
5. $`T`$ の原子がすべて $`h`$ と上端 $`\beta`$ で成り立つ。
6. 制御の原子が $`h`$ と上端 $`\beta`$ で成り立つ。つまり $`R(\mathrm{eval}\,K_c\,h,\ h(p_c),\ \beta)`$ である。

**定理 4（予備つきの継ぎ合わせ）.** 状態 $`(G, F, T, (p_c, K_c), h, \beta)`$ があり、列の数を $`n`$、切れ目を $`\mathrm{cut} = p_c`$ とする。上端の原子の一覧 $`N`$ と、$`n + (n - \mathrm{cut})`$ 個の列の上の内部の原子の一覧 $`H`$ が次を満たすとする。

- $`N`$ の各原子 $`(p, K)`$ に、$`T`$ の原子 $`(p, K')`$ で $`K \le K'`$ のものがある（$`N`$ は $`T`$ で覆われる）。
- $`N`$ の各原子 $`(p, K)`$ で $`K \lt K_c`$ である。
- $`H`$ の原子はどれも、§6 の意味で分類される。ただし 2 の元の原子は $`G`$ または $`F`$ から取る。

このとき、新しいラベル $`h'`$ があって、$`(H, \sigma(F), \sigma(T), (\sigma(p_c), \sigma(K_c)), h', \beta)`$ は状態である。$`\sigma(F)`$ は $`F`$ の各原子の列と型板に $`\sigma`$ を当てたもので、$`\sigma(T)`$ も同じである。

**証明.** 図式 $`(G \cup F, N)`$、$`\theta = \mathrm{eval}\,K_c\,h`$、切れ目 $`p_c`$、上端 $`\beta`$ で有限反映を使う。仮定 3 の鍵の条件は、$`K \lt K_c`$ と定理 1 から出る。$`N`$ が上端 $`\beta`$ で成り立つことは、$`T`$ の原子と定理 1 と鍵の弱化から出る。仮定 4 は状態の 6 である。得た $`g`$ から $`h'`$ を作る。定理 3 から、$`h'`$ は狭義増加で $`h' \lt \beta`$、$`H`$ は $`h'`$ で成り立つ。$`h' \circ \sigma = h`$ と付け替えの式から、$`\sigma(F)`$、$`\sigma(T)`$、$`\sigma`$ で写した制御の原子は、$`F`$、$`T`$、制御の原子と同じ関係になり、成り立つ。$`\square`$

**継ぎ合わせの番号.** 展開 $`s[n]`$（$`s_{x_0} \gt 1`$、$`n \ge 1`$）で使う。$`i = 0, 1, \ldots, n-1`$ について、$`i`$ 回目の継ぎ合わせでは次のとおりである。

- 今の列は $`0, \ldots, x_0 + i \cdot w - 1`$ で、列の数は $`x_0 + i \cdot w`$ である。
- 切れ目は $`c_r + i \cdot w`$ である。移す写像は $`\sigma_i(j) = j`$（$`j \lt c_r + i \cdot w`$）、$`\sigma_i(j) = j + w`$（$`j \ge c_r + i \cdot w`$）で、$`\sigma_i \circ \mu_i = \mu_{i+1}`$ である。
- 新しく足す列は $`x_0 + i \cdot w, \ldots, x_0 + (i+1) \cdot w - 1`$ で、境目の列は $`x_0 + i \cdot w`$ である。[05](05-omegay-mountain.md) §5.1 のブロックで言うと、列 $`x_0 + i \cdot w`$ はブロック $`i`$ の列（$`x = x_0`$ の写し）で、残りはブロック $`i + 1`$ の列（$`x = c_r + 1, \ldots, x_0 - 1`$ の写し）である。
- 予備と制御の原子は $`\mu_i`$ で写したもの $`\mu_i(F)`$、$`\mu_i(T)`$、$`(c_r + i \cdot w, \mu_i(K_c))`$ を使う。

**定理 5（くり返し）.** 状態 $`(G_0, F, T, (c_r, K_c), h_0, \beta)`$ があり、$`h_0`$ の列は $`0, \ldots, x_0 - 1`$ とする。各 $`i \lt n`$ で、上端の原子の一覧 $`N_i`$ と内部の原子の一覧 $`G_{i+1}`$ が、$`\mu_i`$ で写した予備と制御の原子について定理 4 の仮定を満たすとする。このとき、すべての $`i \le n`$ で、状態 $`(G_i, \mu_i(F), \mu_i(T), (c_r + i \cdot w, \mu_i(K_c)), h_i, \beta)`$ がある。$`h_i`$ の列は $`0, \ldots, x_0 + i \cdot w - 1`$ である。$`\beta`$ は変わらない。

**証明.** $`i`$ についての帰納法で、定理 4 を使う。$`\sigma_i \circ \mu_i = \mu_{i+1}`$ なので、写した予備は次の回の形になる。$`\square`$

## 8. 分類と降下

原子の系 $`E`$ を 1 つ決める。空でない式 $`s`$ と $`n \ge 1`$ で、$`s_{x_0} \gt 1`$ とする。$`D`$ を $`M(s)`$ の次数の上界とする。

- $`F`$：$`E(M(s))`$ の原子で、子の列が $`x_0`$ より小さいもの。
- $`T`$：$`E(M(s))`$ の原子 $`(p, x_0, K)`$ を、上端の原子 $`(p, K)`$ と読んだもの。
- 制御：$`E(M(s))`$ の原子 $`(c_r, x_0, K_c)`$ の 1 つを、上端の原子 $`(c_r, K_c)`$ と読んだもの。どれを選ぶかは系ごとに決める。

**定義（分類）.** $`E(M(s[n]))`$ の原子 $`(P, X, K)`$ が **分類される** とは、次のどれかであることをいう。

- **(基)** $`X \lt x_0`$ で、$`E(M(s))`$ に原子 $`(P, X, K')`$ があって $`K \le K'`$ である。
- $`X \ge x_0`$ のときは、$`x_0 + i \cdot w \le X \lt x_0 + (i+1) \cdot w`$ となる $`i`$ を取る。
- **(予備)** $`P \lt c_r`$ または $`P \ge x_0 + i \cdot w`$ である。$`P' = P`$（$`P \lt c_r`$ のとき）、$`P' = c_r + P - (x_0 + i \cdot w)`$（$`P \ge x_0 + i \cdot w`$ のとき）とする。$`F`$ に原子 $`(P', c_r + X - (x_0 + i \cdot w), K')`$ があって、$`K \le \mu_{i+1}(K')`$ である。
- **(継ぎ目)** $`X = x_0 + i \cdot w`$ で、$`K \lt \mu_i(K_c)`$ である。さらに $`T`$ に原子 $`(\ell, x_0, K')`$ があって、$`\mu_i(\ell) = P`$ かつ $`K \le \mu_i(K')`$ である。

(予備) は定理 4 の分類の 2 に、(継ぎ目) は分類の 3 に当たる。(予備) の元の原子 $`(P', \ldots, K')`$ を $`\mu_i`$ で写し、さらに $`\sigma_i`$ で写すと、列が $`(P, X)`$ で型板が $`\mu_{i+1}(K')`$ になる。(継ぎ目) では $`N_i`$ に上端の原子 $`(P, K)`$ を入れる。これは $`\mu_i(T)`$ で覆われ、鍵は $`\mu_i(K_c)`$ より小さい。

**定理 6（降下）.** $`s`$ を空でない式、$`n`$ を自然数、$`D`$ を $`M(s)`$ の次数の上界とし、$`s[n]`$ が定まるとする。次を仮定する。

1. $`M(s[n])`$ が作れて、$`D`$ はその次数の上界でもある。
2. $`s_{x_0} \gt 1`$ かつ $`n \ge 1`$ なら、$`s[n]`$ の長さは $`x_0 + n \cdot w`$ で、$`E(M(s[n]))`$ の原子はどれも分類される。

このとき、$`M(s)`$ の $`E`$ についての表現 $`f`$ から、$`M(s[n])`$ の表現 $`f'`$ で、どのラベルも $`f(x_0)`$ より小さいものが作れる。

**証明.** $`s_{x_0} = 1`$ または $`n = 0`$ のとき、$`s[n]`$ は $`s`$ の接頭辞である。§4 の接頭辞の性質から、$`f`$ を列 $`0, \ldots, x_0 - 1`$ に制限すればよい。$`f`$ は狭義増加なので、どのラベルも $`f(x_0)`$ より小さい。

それ以外のとき、$`\beta = f(x_0)`$ とする。$`G_i`$ を $`E(M(s[n]))`$ の原子で子の列が $`x_0 + i \cdot w`$ より小さいもの、$`N_i`$ を (継ぎ目) の原子のうち $`X = x_0 + i \cdot w`$ のものから作った上端の原子とする。

- 状態 0：$`h_0`$ は $`f`$ を列 $`0, \ldots, x_0 - 1`$ に制限したものである。$`G_0`$ は (基) と鍵の弱化で成り立つ。$`F`$ は $`f`$ で成り立つ。$`T`$ と制御の原子は、$`E(M(s))`$ の原子で子の列が $`x_0`$ なので、上端 $`\beta = f(x_0)`$ で成り立つ。$`h_0 \lt \beta`$ である。
- 各 $`i`$ で、$`G_{i+1}`$ の原子は、子の列が $`x_0 + i \cdot w`$ より小さければ $`G_i`$ の原子で、そうでなければ (予備) か (継ぎ目) で分類される。定理 5 の仮定が成り立つ。
- 定理 5 から、状態 $`(G_n, \ldots, h_n, \beta)`$ がある。$`G_n`$ は $`E(M(s[n]))`$ の全体で、$`h_n`$ の列の数は $`x_0 + n \cdot w`$ で $`s[n]`$ の長さに等しい。$`h_n \lt \beta \lt \omega_1`$ なので、$`h_n`$ が求める表現である。$`\square`$

**整礎性.** [02](02-well-founded.md) §6 の定理を、次のように当てはめる。$`D`$ を 1 つ固定する。

| 一般形 | ここでの当てはめ |
|---|---|
| 状態 | 山が作れて、$`D`$ が次数の上界である有限列 $`s`$ |
| 1 歩の関係 | $`t \prec s`$（[05](05-omegay-mountain.md) §8） |
| ラベル | $`\omega_1`$ 以下の順序数 |
| $`\mathrm{valid}(s, \alpha)`$ | $`M(s)`$ に $`E`$ についての表現があり、どのラベルも $`\alpha`$ より小さい |
| $`\alpha_0`$ | $`\omega_1`$（最初の表現の定理を、図式 $`(E(M(s)), \emptyset)`$ に使う） |
| $`\alpha'`$ | 古い表現の最後の列のラベル $`f(x_0)`$ |

定理 6 の仮定がすべての $`s, n`$ で成り立てば、状態の集合は $`\prec`$ で閉じていて、[02](02-well-founded.md) §6 の定理の 2 つの条件が成り立つ。よって、この集合の上で $`\prec`$ は整礎である。無限列 $`s_0 \succ s_1 \succ \cdots`$ があれば、$`s_0`$ は展開できるので山が作れる。その次数の上界を $`D`$ とすると、列はすべてこの集合に入り、矛盾する。だから $`\prec`$ は有限列の全体の上で整礎である。

## 9. 山の辺では足りない

山の辺の系（§4）で、制御を列 $`x_0`$ の一番上の辺（上の節点が $`t`$ の辺。親は根 $`r`$）の原子にすると、公式の ω-Y では分類が破れる。

**例（$`(1,3,3)[2]`$、Python で計算した）.** $`c_r = 0`$、$`w = 2`$、$`x_0 = 2`$ である。出力の列 4 の辺 $`(4,0) \to (4,1)`$ は、親が列 3 の行 0 の節点である（[05](05-omegay-mountain.md) §6.1 の、行 1 のすき間の写し）。その原子は $`(3, 4, (0, 0))`$ である。

- $`X = 4 = x_0 + 1 \cdot w`$ なので $`i = 1`$ で、境目の列である。
- $`P = 3`$ は $`c_r = 0`$ より小さくなく、$`x_0 + i \cdot w = 4`$ 以上でもない。(予備) に入らない。
- (継ぎ目) には、$`T`$ に $`\mu_1(\ell) = 3`$、つまり $`\ell = 1`$ の原子、すなわち列 1 から列 2 への原子が要る。しかし $`M(1,3,3)`$ の列 2 の辺の親は、どれも列 0 にある。$`T`$ は $`(0, 2, (0, 0))`$ と $`(0, 2, (0, \top))`$ だけである。

**試験（Python）.** 長さ 5 以下・値 5 以下の式（末項が 1 のものを除く）と $`n = 1, 2, 3`$ の 1872 回の展開のうち、328 回で山の辺の系の分類が破れた。weak-magma ω-Y では、Phyrion 氏がこの系で証明した。

## 10. 脚の原子

山の辺の代わりに、節点ごとに 1 つの原子を置く。$`M`$ を山、$`D`$ を次数の上界とする。

**定義（脚、脚の先）.** 列 $`c \ge 1`$ の節点 $`u`$ の **脚** $`\ell(u)`$ は、$`u`$ が最下の節点でなければ $`\mathrm{col}\,\pi(u)`$（$`u`$ へ下から入る辺の親の列）、最下の節点なら $`c - 1`$ である。**脚の先** $`p_u`$ は、列 $`\ell(u)`$ の節点で、行が $`\mathrm{row}(u)`$ 以下の最も高いものである。列 $`\ell(u)`$ には行 0 の節点があるので、いつも定まる。

**定義（仮の鍵）.** 節点 $`u`$ と節点 $`p`$ について、$`d = \mathrm{jump}(\mathrm{row}(u), \mathrm{row}(p))`$ とする。**仮の鍵** $`\kappa_D(u; p)`$ は長さ $`D + 1`$ の型板で、尺度 $`k`$ の座標は、$`d \le k`$ なら $`\mathrm{col}\,\rho_k(p)`$、そうでなければ $`\top`$ である。$`u`$ から $`p`$ へ辺があるとしたときの辺の鍵である。仮の鍵と区別するため、山に実際にある辺を **本物の辺** と呼ぶ。

**定義（脚の原子）.** $`\mathrm{at}(u) = (\ell(u),\ \mathrm{col}(u),\ \kappa_D(u; p_u))`$ を $`u`$ の **脚の原子** と呼ぶ。**脚の原子の系** $`E_D(M)`$ は、列 1 以上のすべての節点の脚の原子の一覧である。制御は $`\mathrm{at}(t) = (c_r, x_0, K_c)`$ とする。$`t`$ へ下から入る辺の親は根 $`r`$ なので、$`\ell(t) = c_r`$ である。

**例 1（$`(1,3,5)`$、$`D = 1`$、Python で計算した）.** 列 2 の節点の脚の原子は次のとおりである。

| 節点 | 脚 | 脚の先 | 跳び | 鍵 |
|---|---|---|---|---|
| $`(2, 0)`$ | 1 | $`(1, 0)`$ | 0 | $`(0, 0)`$ |
| $`(2, 1)`$ | 1 | $`(1, 1)`$ | 0 | $`(0, 1)`$ |
| $`(2, \omega)`$ | 0 | $`(0, 0)`$ | 2 | $`(\top, \top)`$ |

$`(2, 1)`$ の鍵の尺度 0 の座標は 1 である。$`(1, 1)`$ から上への辺は跳び 1 なので、尺度 0 の親が無く、$`\rho_0((1,1)) = (1,1)`$ だからである。

**例 2（$`(1,3,4)[1] = (1,3,3)`$）.** $`M(1,3,4)`$ の列 2 は `0:4, 1:1←c1@0` で、$`c_r = 1`$、$`w = 1`$ である。$`t = (2, 1)`$、$`\ell(t) = 1`$、$`p_t = (1, 1)`$、跳び 0 なので、$`K_c = (0, 1)`$ である。本物の辺 $`(2,0) \to (2,1)`$ の鍵 $`(0, 0)`$ より大きい。

出力 $`(1,3,3)`$ の列 2 は境目の列 $`x_0 + 0 \cdot w`$ である。その最下の節点の脚の原子は $`(1, 2, (0, 0))`$ である。$`(0, 0) \lt \mu_0(K_c) = (0, 1)`$ で、$`T`$ の $`\mathrm{at}(t) = (1, 2, (0, 1))`$ で覆われるので、(継ぎ目) で分類される。制御が本物の辺の $`(0, 0)`$ なら、$`(0, 0) \lt (0, 0)`$ が成り立たないので分類されない。$`(1,3,3)`$ の表現には列 1 と列 2 の関係が要る。それを $`(1,3,4)`$ の表現から反映で作るには、制御が本物の辺より強くなければならない。

**例 3（$`(1,3,3)[2]`$）.** $`K_c = (\top, \top)`$ である（$`\mathrm{at}((2, \omega)) = (0, 2, (\top, \top))`$）。$`M(1,3,3)`$ の $`(2, 0)`$ の脚の原子は $`(1, 2, (0, 0))`$ で、$`T`$ に入る。これを $`\mu_1`$ で写すと $`(3, 4, (2, 2))`$ である。§9 の出力の原子 $`(3, 4, (0, 0))`$（これは出力の $`(4, 0)`$ の脚の原子でもある）は、$`(0, 0) \le (2, 2)`$ と $`(0, 0) \lt (\top, \top)`$ から (継ぎ目) で分類される。

**性質（試した範囲で成り立つもの）.** 辺 $`(u, u^+)`$ の親の列は $`\ell(u^+)`$ で、辺の鍵は $`\mathrm{at}(u^+)`$ の鍵以下である。したがって $`E_D`$ の表現は、鍵の弱化で山の辺の系の表現にもなる。長さ 5 以下・値 5 以下の式 624 個の山の辺 4073 本で成り立つことを Python で確かめた。ここでは証明しない。

**一番上の節点の脚の原子.** 一番上の節点 $`u`$ には上への辺が無い。$`\mathrm{at}(u)`$ は、$`u`$ の上にさらに節点があったら出たはずの辺の鍵を持つ。脚の先が低いと跳び $`d`$ が大きくなり、鍵の座標の多くが $`\top`$ になる。例えば $`(1,3,3)`$ の列 2 の一番上の節点（行 $`\omega`$）では $`\mathrm{at}(u) = (0, 2, (\top, \top))`$ である。制御 $`\mathrm{at}(t)`$ もこの形の原子である。

## 11. 分類の補題

**分類の補題.** すべての空でない式 $`s`$、自然数 $`n`$、$`M(s)`$ の次数の上界 $`D`$ について、$`s[n]`$ が定まるなら、次が成り立つ。

1. 出力の山 $`M(s[n])`$ が作れる。
2. $`D`$ は $`M(s[n])`$ の次数の上界でもある。
3. $`s_{x_0} \gt 1`$ かつ $`n \ge 1`$ なら、$`s[n]`$ の長さは $`x_0 + n \cdot w`$ である。そうでなければ、長さは $`x_0`$ である（末項を消す）。
4. $`E_D(M(s[n]))`$ の原子はどれも、$`E_D(M(s))`$ と制御 $`\mathrm{at}(t)`$ について §8 の意味で分類される。

証明は [10](10-official-descent.md) で与える。ここではまだ証明しない。この補題は定理 6 の仮定そのものなので、§8 と合わせて [05](05-omegay-mountain.md) §8 の最終定理が出る。

**試験（Python）.** 長さ 5 以下・値 5 以下の式（末項が 1 のものを除く）と $`n = 1, 2, 3`$ の 1872 回の展開で、1〜4 の失敗は 0 回だった。$`D`$ を $`M(s)`$ の次数そのものにした場合も、1 大きくした場合も同じである。
